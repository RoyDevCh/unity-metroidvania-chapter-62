# 冲刺冷却

## 🎯 本节目标
学习如何利用 `Time.deltaTime` 创建一个冷却计时器，确保 Dash 技能不能被连续无限制地触发，从而增加游戏的平衡性。

## 🖥️ 操作步骤

### 1. 定义冷却相关变量
我们需要一个用于设置冷却时长（配置值）的变量，以及一个用于实时计算剩余时间的计时器变量。

```csharp
[SerializeField] private float dashCooldown = 0.4f; // 冷却时间间隔
private float dashCooldownTimer; // 内部计时器
```
- `dashCooldown`: 在 Inspector 面板中设置，决定两次 Dash 之间需要等待多久。
- `dashCooldownTimer`: 用于在 `Update` 中递减，追踪当前冷却状态。

![定义变量](../screenshots/020_new1.jpg)

### 2. 实现计时器递减逻辑
在 `Update` 方法中，我们需要让计时器随时间流逝而减少。

```csharp
void Update()
{
    // 每一帧都减去经过的时间，使计时器向负数方向递减
    dashCooldownTimer -= Time.deltaTime;

    // ... 其他逻辑
}
```
- `Time.deltaTime` 确保了计时与帧率无关，在任何设备上速度一致。

### 3. 编写 Dash 触发条件判断
使用逻辑与运算符 `&&` 检查：玩家是否按下了按键 **且** 冷却计时器是否已归零（小于 0）。

```csharp
// 在 CheckInput 或相关逻辑中
if (Input.GetKeyDown(KeyCode.LeftShift) && dashCooldownTimer <= 0)
{
    // 执行 Dash 逻辑
    // ...

    // 触发后立即重置计时器为最大冷却值
    dashCooldownTimer = dashCooldown;
}
```
- 当 `dashCooldownTimer <= 0` 时，表示冷却已结束，允许执行。
- 执行瞬间将 `dashCooldownTimer` 设回 `dashCooldown`，使其立即变为正数，从而在接下来的时间内阻止再次触发。

![逻辑判断](../screenshots/020_new2.jpg)

### 4. 代码重构与优化
为了保持代码整洁，我们将 Dash 的逻辑从输入检测中提取到独立的方法 `DashAbility` 中。

```csharp
private void CheckInput()
{
    if (Input.GetKeyDown(KeyCode.LeftShift))
    {
        DashAbility();
    }
}

private void DashAbility()
{
    if (dashCooldownTimer <= 0)
    {
        // 启动 Dash 效果
        // (此处包含之前章节实现的 dash 速度和时间设置)

        dashCooldownTimer = dashCooldown;
    }
}
```
- **重构目的**：`CheckInput` 仅负责检测按键，`DashAbility` 负责处理技能逻辑（包括冷却检查），使结构更清晰。

## 💻 完整代码

```csharp
using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    [Header("Dash Settings")]
    [SerializeField] private float dashSpeed = 20f;
    [SerializeField] private float dashDuration = 0.2f;
    [SerializeField] private float dashCooldown = 0.4f;

    private float dashTime;
    private float dashCooldownTimer;

    void Update()
    {
        // 计时器持续递减
        dashTime -= Time.deltaTime;
        dashCooldownTimer -= Time.deltaTime;

        CheckInput();
    }

    private void CheckInput()
    {
        // 检测 Shift 键
        if (Input.GetKeyDown(KeyCode.LeftShift))
        {
            DashAbility();
        }
    }

    private void DashAbility()
    {
        // 只有在冷却时间结束（<=0）时才允许 Dash
        if (dashCooldownTimer <= 0)
        {
            // 激活 Dash 状态
            dashTime = dashDuration;
            dashCooldownTimer = dashCooldown; // 重置冷却计时器

            Debug.Log("Dash Triggered!");
        }
    }
}
```

## 📝 核心要点
- **冷却逻辑公式**：`计时器 -= Time.deltaTime` $\rightarrow$ `判断 计时器 <= 0` $\rightarrow$ `触发后 计时器 = 冷却值`。
- **Time.deltaTime**：是实现所有时间相关功能（冷却、计时、平滑移动）的核心 API。
- **代码解耦**：将“输入检测”与“能力执行”分开编写，方便后续维护和扩展。
- **调试技巧**：在测试阶段可以将 `dashCooldown` 设为一个较大的值（如 10 秒），以便直观观察计时器在 Inspector 中的变化。
