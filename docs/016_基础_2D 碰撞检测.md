## 🎯 本节目标

使用 `Physics2D.Raycast` 实现地面检测，为跳跃动画和防止无限连跳提供基础。

---

## 🖥️ 操作步骤

### 步骤 1：创建 GroundCheck 检测点

1. 在 Hierarchy 中右键 Player → Create Empty
2. 命名 `GroundCheck`，放置在角色**脚底**位置（Y 轴略低于碰撞体底部）
3. 将 GroundCheck 拖到 Player 上使其成为**子对象**

![射线检测点](../screenshots/016_ray.jpg)

---

### 步骤 2：添加碰撞检测变量

```csharp
[Header("Collision Info")]
[SerializeField] private Transform groundCheck;
[SerializeField] private float groundCheckDistance = 0.2f;
[SerializeField] private LayerMask whatIsGround;

private bool isGrounded;
```

![GroundCheck配置](../screenshots/016_ground_check.jpg)

---

### 步骤 3：实现射线检测

```csharp
void Update()
{
    // 地面检测：从脚底向下发射射线
    isGrounded = Physics2D.Raycast(groundCheck.position, Vector2.down,
                                     groundCheckDistance, whatIsGround);

    // 只有在地面上才能跳跃
    if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
    {
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);
    }

    // 动画参数
    anim.SetBool("isGrounded", isGrounded);
}
```

> 🔑 `Physics2D.Raycast(起点, 方向, 距离, 层级)` — 只检测指定层，避免误判。

---

### 步骤 4：设置 Layer

1. 选中 Platform → Inspector → Layer → Add Layer → 新增 `Ground`
2. 给所有平台对象设为 `Ground` 层
3. 选中 Player → Player Script → `whatIsGround` 勾选 `Ground`

---

### 步骤 5：可视化调试

添加 `OnDrawGizmos` 来直观看到射线范围：

```csharp
private void OnDrawGizmos()
{
    Gizmos.DrawLine(groundCheck.position,
                    groundCheck.position + new Vector3(0, -groundCheckDistance));
}
```

Scene 视图中会看到一条从脚底向下的绿线——线碰到平台 = `isGrounded = true`。

## 💻 完整代码

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    [SerializeField] private float moveSpeed = 8f;
    [SerializeField] private float jumpForce = 12f;

    [Header("Collision")]
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float groundCheckDistance;
    [SerializeField] private LayerMask whatIsGround;

    private Rigidbody2D rb;
    private Animator anim;
    private float xInput;
    private bool isGrounded;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        anim = GetComponent<Animator>();
    }

    void Update()
    {
        xInput = Input.GetAxisRaw("Horizontal");
        rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);

        isGrounded = Physics2D.Raycast(groundCheck.position, Vector2.down,
                                         groundCheckDistance, whatIsGround);

        if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
        {
            rb.velocity = new Vector2(rb.velocity.x, jumpForce);
        }

        if (xInput < 0) transform.localScale = new Vector3(-1, 1, 1);
        else if (xInput > 0) transform.localScale = new Vector3(1, 1, 1);

        anim.SetFloat("xVelocity", Mathf.Abs(rb.velocity.x));
        anim.SetBool("isGrounded", isGrounded);
    }

    private void OnDrawGizmos()
    {
        Gizmos.DrawLine(groundCheck.position,
            groundCheck.position + new Vector3(0, -groundCheckDistance));
    }
}
```

---

## 📝 核心要点

```
Physics2D.Raycast(origin, direction, distance, layerMask)
  → 返回 bool / RaycastHit2D

  origin:    检测起点（脚底 GroundCheck 位置）
  direction: Vector2.down（向下）
  distance:  0.2f 左右（太大会误判，太小检测不到）
  layerMask: 只检测 Ground 层（避免碰到自身或敌人）

isGrounded → 控制能否跳跃 + 动画状态
```
