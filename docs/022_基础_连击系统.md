## 🎯 本节目标

实现多段连击——在连击窗口 `comboWindow` 内再次点击可打出下一段攻击，超时则从第 1 段重新开始。

> 🧩 本节建立在 [[021_基础_攻击动画]] 的结构之上：沿用鼠标左键 `Input.GetMouseButtonDown(0)` → `Attack()` 触发、`public void AttackOver()` 结束的框架，`Update` 三方法顺序不变，只在攻击中追加连击判定。

---

## 🖥️ 操作步骤

### 步骤 1：添加多个攻击动画

创建3段攻击动画片段：`playerAttack1`、`playerAttack2`、`playerAttack3`

每段动画最后一帧加 **Animation Event** → `AttackOver()`

---

### 步骤 2：设置连击变量

```csharp
[Header("Attack Info")]
[SerializeField] private float comboWindow = 0.5f;  // 连击窗口：上次攻击后这段时间内再按才算连击

private bool isAttacking;              // 是否正在攻击（上一节引入）
private int comboCounter;              // 当前连击段数：0 → Attack1 / 1 → Attack2 / 2 → Attack3
private float lastAttackTime = -999f;  // 上一次按下攻击键的时间（初始取极小值，保证第一次点击从第 1 段开始）
```

### 步骤 3：连击判定与攻击输入

输入框架与上一节一致：`CheckInput()` 检测鼠标左键并调用 `Attack()`，连击判定放在 `Attack()` 内部：

```csharp
private void CheckInput()
{
    xInput = Input.GetAxisRaw("Horizontal");

    if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);

    if (Input.GetKeyDown(KeyCode.LeftShift) && dashCooldownTimer <= 0)
        StartDash();

    // 攻击输入：鼠标左键（与上一节相同）
    if (Input.GetMouseButtonDown(0))
        Attack();
}

private void Attack()
{
    // 连击判定：仍在窗口内 → 下一段；超出窗口 → 从第 1 段重新开始
    if (Time.time < lastAttackTime + comboWindow)
        comboCounter++;
    else
        comboCounter = 0;

    if (comboCounter > 2)          // 3 段全部打完，绕回第 1 段
        comboCounter = 0;

    isAttacking = true;
    lastAttackTime = Time.time;    // 记录本次攻击时间，供下次判定使用

    anim.SetInteger("comboCounter", comboCounter);  // 决定切到哪一段攻击动画
    anim.SetBool("isAttacking", true);
}
```

> 🔑 用 `Time.time`（游戏运行累计时间）比较两次攻击的间隔即可，无需额外倒计时变量。

---

### 步骤 4：Animation Event 回调 AttackOver

每段攻击动画末帧的 Animation Event 调用 `AttackOver()`，实现与 [[021_基础_攻击动画]] 完全一致：

```csharp
// 必须是 public，由 Animation Event 调用
public void AttackOver()
{
    isAttacking = false;
    anim.SetBool("isAttacking", false);
}
```

> 💡 `isAttacking` 置 false 后玩家恢复操作；若仍在 `comboWindow` 窗口内再次点击，就进入下一段连击。

---

### 步骤 5：并入 Update 固定结构

三方法调用顺序不变，攻击期间提前 `return`；结束时机交给 Animation Event，不需要计时器兜底：

```csharp
void Update()
{
    if (dashCooldownTimer > 0)
        dashCooldownTimer -= Time.deltaTime;

    if (isDashing)
    {
        HandleDashing();
        return;
    }

    // 攻击期间站定不动，等 Animation Event 调用 AttackOver() 结束
    if (isAttacking)
    {
        rb.velocity = new Vector2(0, rb.velocity.y);
        return;
    }

    Movement();
    CheckInput();
    AnimatorControllers();
}
```

### 步骤 6：Animator 状态机设置

![Animator连击状态](../screenshots/022_2.jpg)

参数：`comboCounter` (Int)

过渡逻辑：
- `Any State` → `playerAttack1`：Condition `isAttacking && comboCounter == 0`
- `Any State` → `playerAttack2`：Condition `isAttacking && comboCounter == 1`
- `Any State` → `playerAttack3`：Condition `isAttacking && comboCounter == 2`

所有 Transition：**Has Exit Time: ❌**，**Transition Duration: 0**

> 💡 每段攻击动画 → `playerIdle` 的过渡保留 Has Exit Time ✅（同上一节），动画播完自动返回 Idle。

{

{

    anim.SetBool("isAttacking", false);
}

## 📝 核心要点

```
连击流程（comboWindow = 0.5s 为例）：
  第 1 次点击 → 超出上次窗口 → comboCounter = 0 → Attack1
  Attack1 播完 → Animation Event → AttackOver() → isAttacking = false
  0.5s 内第 2 次点击 → Time.time < lastAttackTime + comboWindow → comboCounter++ → Attack2
  同理第 3 次 → Attack3
  再点击时 comboCounter 超过 2 → 归零回 Attack1

超时重置：
  窗口外才点击 → Time.time >= lastAttackTime + comboWindow → comboCounter 归零 → 从 Attack1 重新开始

衔接上一节：
  输入入口 GetMouseButtonDown(0)、参数 isAttacking、回调 public void AttackOver() 全部不变
  新增的只有 comboWindow / comboCounter / lastAttackTime 与 SetInteger("comboCounter")
```
