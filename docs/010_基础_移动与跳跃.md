## 🎯 本节目标

让角色能够**左右移动**和**按空格跳跃**。

> **课程阶段核对**：视频原版把 `Rigidbody2D rb` 声明为 `public`，在 Inspector 手动拖入，并把初始化时机放在 `Start()`；视频中的移动速度在 Inspector 里先设为 `4`。本页的 `Awake() + GetComponent`、`moveSpeed = 8f` 是后续整理后的等价推荐写法，不是这一节截图的逐行代码。两种注入方式选一种即可，不能既拖引用又再声明第二个 `rb`。

---

## 🖥️ 操作步骤

### 步骤 1：理解 public 和 private 的区别

打开 `Player.cs`，先理解变量声明的规则：

| 关键字 | Inspector 可见？ | 其他脚本能访问？ |
|--------|:---:|:---:|
| `public` | ✅ | ✅ |
| `private` | ❌ | ❌ |

> **简单理解**：`public` = 在 Inspector 中可见，其他脚本也能访问；`private` = Inspector 中不可见（显示为隐藏），其他脚本也无法访问。移动速度、跳跃力度这些需要调试的值用 `public`（或 `[SerializeField] private`），内部临时变量用 `private`。视频中先声明 `public Rigidbody2D rb;` 并在 Inspector 里拖入组件赋值。

---

### 步骤 2：获取 Rigidbody2D 组件（推荐整合写法）

在 `Player.cs` 中声明一个 `Rigidbody2D` 类型的变量，然后在 `Awake()` 中自动获取组件：

```csharp
public class Player : MonoBehaviour
{
    private Rigidbody2D rb;
    private float xInput;          // 存储左右输入值

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();   // 自动获取自己身上的刚体组件
    }

    void Update()
    {
        xInput = Input.GetAxisRaw("Horizontal");   // -1(左), 0(停), 1(右)
    }
}
```

![初始代码](../screenshots/010_code1.jpg)

> 💡 `Input.GetAxisRaw("Horizontal")` 的返回值：按 **A/←** → `-1`，不按 → `0`，按 **D/→** → `1`

---

### 步骤 3：实现左右移动

利用刚体的 `velocity`（速度）来驱动移动。Vector2 的 `x` 分量控制水平方向：

```csharp
void Update()
{
    xInput = Input.GetAxisRaw("Horizontal");

    // 设置水平速度 = 输入值 × 移动速度
    // Y轴速度保持原样，不受影响
    rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);
}
```

> 🔑 **Vector2 速查**：`(x, y)` → x 控制左右（正=右，负=左），y 控制上下（正=上，负=下）。

---

### 步骤 4：添加可调节的移动速度

把速度值暴露到 Inspector 中，方便调试：

```csharp
public float moveSpeed = 8f;   // Inspector 中可拖动滑块调整
```

回到 Unity，选中 Player，在 Inspector 中将 `moveSpeed` 设为 `8`。点 Play 测试——按 A/D 或 ←/→ 就可以左右移动了。

---

### 步骤 5：实现跳跃

跳跃 = 给 Y 轴一个向上的瞬间速度：

```csharp
public float jumpForce = 7f;   // 跳跃力度（视频中设为 7，可在 Inspector 随意调整）

void Update()
{
    xInput = Input.GetAxisRaw("Horizontal");
    rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);

    // 按空格键跳跃
    if (Input.GetKeyDown(KeyCode.Space))
    {
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);
    }
}
```

![最终代码](../screenshots/010_code2.jpg)

> ⚠️ `Input.GetKeyDown` 只在按下**瞬间**触发一次，适合跳跃/攻击。`Input.GetKey` 持续按住才触发，适合蓄力。

---

### 步骤 6：在 Unity 中配置并测试

![场景预览](../screenshots/010_scene.jpg)

## 💻 完整代码

> 以下是便于继续后续章节的推荐整合版。若目标是逐帧复刻视频，请保留 `public Rigidbody2D rb`，在 Inspector 赋值，并把初始化相关代码放在 `Start()`；运动和跳跃主体逻辑相同。

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    private Rigidbody2D rb;
    private float xInput;

    public float moveSpeed = 8f;
    public float jumpForce = 7f;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        xInput = Input.GetAxisRaw("Horizontal");
        rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);

        if (Input.GetKeyDown(KeyCode.Space))
        {
            rb.velocity = new Vector2(rb.velocity.x, jumpForce);
        }
    }
}
```
