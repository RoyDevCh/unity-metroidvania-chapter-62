# 视差背景

> **关卡** | 第 46/192 节 | [[045_关卡_Cinemachine 摄像机跟随|⬅️ Cinemachine 摄像机跟随]] | [[047_关卡_无尽背景|➡️ 无尽背景]]

## 🎯 本节目标

配置 **Sorting Layer**（Background / Ground / Enemy / Player），搭建多层城堡背景，并用脚本让背景随摄像机缓慢移动，形成 **Parallax（视差）** 氛围。

## 🖥️ 操作步骤

### 1. 导入背景并修正 Sorting Layer

1. `Graphics → surroundings → medieval castle → background`，将天空与城墙两层拖入场景。
2. 若挡住玩家/平台：在 **Sorting Layers** 中新增 `Background`、`Ground`、`Enemy`、`Player`（越靠下越靠前）。
3. 平台 Tilemap 使用 **Ground**；城墙用 **Background**。
4. 天空层 **Order in Layer** 设为 `-10`，城墙层 `-9`，保证层次：天空最远 → 城墙 → 地面 → 角色。

![图层与排序](../screenshots/046_1.jpg)

### 2. 组织层级与拉长背景

1. 选中背景相关对象，**Reset Position**，创建空父物体 `Background`。
2. 复制天空与城墙各两份，分别向左/右偏移约 **±40**，作为视差延伸段。
3. 修补场景中背景接缝（用 Tile 或移动 Sprite 填洞）。

![拉长背景](../screenshots/046_2.jpg)

### 3. 编写视差脚本

1. 创建脚本 `ParallaxBackground`（或课程中的 `AlexaBackground`），挂到需要移动的层上。
2. 在 `Start` 中 `cam = GameObject.Find("Main Camera")`（或拖引用），记录初始 `xPosition`。
3. 在 `Update` 中：`distanceToMove = cam.transform.position.x * parallaxEffect`，再设置 `transform.position.x = xPosition + distanceToMove`。
4. 城墙层 `parallaxEffect ≈ 0.9`，天空层 `≈ 1`（数值越大，跟随越快）。

![脚本与参数](../screenshots/046_3.jpg)

## 💻 完整代码

```csharp
using UnityEngine;

public class ParallaxBackground : MonoBehaviour
{
    [SerializeField] private float parallaxEffect = 0.9f;
    private GameObject cam;
    private float xPosition;

    private void Start()
    {
        cam = GameObject.Find("Main Camera");
        xPosition = transform.position.x;
    }

    private void Update()
    {
        float distanceToMove = cam.transform.position.x * parallaxEffect;
        transform.position = new Vector3(xPosition + distanceToMove, transform.position.y, transform.position.z);
    }
}
```

## 📝 核心要点

- **Sorting Layer + Order in Layer** 决定 2D 前后关系，与物理 Layer 无关。
- **parallaxEffect < 1** 时背景移动慢于摄像机，产生景深。
- 本节背景不必做无限循环；**047** 会在同一脚本上增加无缝回弹逻辑。
