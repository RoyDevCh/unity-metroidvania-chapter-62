# 战斗状态完善

> **敌人AI** | 第 53/192 节 | [[052_敌人AI_敌人攻击实现|⬅️ 敌人攻击实现]] | [[054_战斗_战斗系统设计|➡️ 战斗系统设计]]

## 🎯 本节目标
完善骷髅兵的 `SkeletonBattleState` 逻辑，使其在失去目标（时间超时或距离过远）时能自动返回 `IdleState`，并实现“近身触发”机制：只要玩家贴得足够近，就直接切入 `AttackState`，防止玩家在敌人身后潜行。

## 🖥️ 操作步骤

### 1. 定义战斗维持时间变量
在 `Enemy` 脚本中定义一个公共变量，用于控制敌人在失去目标后继续保持攻击状态的时长。

```csharp
// 在 Enemy.cs 中，靠近 moveSpeed 和 idleTime 的位置添加
public float battleTime;
```
**解释：** `battleTime` 定义了敌人进入“愤怒/追踪”状态后的持续时间。

![定义变量](../screenshots/053_new1.jpg)

### 2. 实现战斗状态的超时退出逻辑
在 `SkeletonBattleState` 中，通过基类提供的 `stateTimer` 字段实现计时功能：进入战斗时赋初值，随后每帧自动递减。

```csharp
// SkeletonBattleState.cs
public override void Enter()
{
    base.Enter();

    // 进入战斗状态时，用 battleTime 启动计时器
    stateTimer = enemy.battleTime;
}

public override void Update()
{
    base.Update();

    // 计时归零且视野内没有玩家时，退回待机状态
    if (stateTimer < 0 && !enemy.IsPlayerDetected())
    {
        stateMachine.ChangeState(enemy.idleState);
    }
}
```
**解释：** 敌人进入战斗状态的瞬间，`stateTimer` 被设置为 `battleTime`（本节设为 7 秒）。一旦玩家消失（如跳上平台），计时器开始倒数，归零且 `enemy.IsPlayerDetected()` 返回 `false` 时，就会切换回 `enemy.idleState`。

### 3. 添加距离检测退出机制
为了防止敌人无限制地追踪远距离目标，把距离判定并入之前的超时判断，组成统一的退出条件。

```csharp
// 在 SkeletonBattleState 的 Update 中合并退出条件
if ((stateTimer < 0 && !enemy.IsPlayerDetected())
    || Vector2.Distance(transform.position, player.transform.position) > 10f) // 这里的 10f 为示例阈值
{
    stateMachine.ChangeState(enemy.idleState);
}
```
**解释：** 使用 `Vector2.Distance` 计算敌人与玩家的实时距离。只要“计时归零且看不到玩家”或“距离超过设定值（如 10 个单位）”任一条件成立，敌人就会认为目标已丢失并退回 `enemy.idleState`。

![距离检测](../screenshots/053_new2.jpg)

### 4. 实现近身触发攻击（防止背后潜行）
先在 `Enemy` 脚本中缓存玩家引用：声明 `protected GameObject player`，并在 `Awake`（或 `Start`）里用 `GameObject.Find` 找到玩家。

```csharp
// 在 Enemy.cs 中定义
protected GameObject player;

protected virtual void Awake()
{
    // 暂时使用 GameObject.Find 作为占位符
    player = GameObject.Find("Player");
}
```

然后在 `SkeletonBattleState` 的 `Update` 中增加贴身判定：即使这一帧没有被视线检测发现，只要玩家距离足够近，就直接切入攻击状态。

```csharp
// 在 SkeletonBattleState 的 Update 中继续添加
if (Vector2.Distance(transform.position, player.transform.position) < 2f)
{
    stateMachine.ChangeState(enemy.attackState);
}
```
**解释：**
- 使用 `GameObject.Find` 是为了快速原型开发（Prototyping），在正式项目中应使用 `PlayerManager` 以优化性能。
- 通过检测距离是否小于 2，实现了即使玩家在敌人背后，只要靠近就会被发现的逻辑，并直接切换到 `enemy.attackState` 发起攻击。

![近身触发](../screenshots/053_new3.jpg)

## 💻 完整代码（逻辑片段）

```csharp
// Enemy.cs 变量与玩家引用部分
public float battleTime = 7f;

protected GameObject player;

protected virtual void Awake()
{
    player = GameObject.Find("Player");
}

// SkeletonBattleState.cs 部分
public override void Enter()
{
    base.Enter();

    // 进入战斗状态时启动计时器
    stateTimer = enemy.battleTime;
}

public override void Update()
{
    base.Update();

    // 超时且看不到玩家，或距离过远，退回待机状态
    if ((stateTimer < 0 && !enemy.IsPlayerDetected())
        || Vector2.Distance(transform.position, player.transform.position) > 10f)
    {
        stateMachine.ChangeState(enemy.idleState);
    }

    // 玩家贴身靠近，直接进入攻击状态
    if (Vector2.Distance(transform.position, player.transform.position) < 2f)
    {
        stateMachine.ChangeState(enemy.attackState);
    }
}
```

## 📝 核心要点
- **状态切换触发器**：战斗状态的退出由 $\text{时间超时} \lor \text{距离过远}$ 共同决定；玩家距离小于 2 时则切入 `AttackState`。
- **性能警示**：`GameObject.Find` 会遍历场景所有对象，性能开销大，仅建议在原型阶段使用，后期应改为单例模式或 Manager 引用。
- **游戏体验**：设置合理的 `battleTime`（如 7 秒）可以让敌人表现出一定的“执念”，增加追逐的紧张感。
