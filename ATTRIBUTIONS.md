# Chapter 62 art attributions

The runtime demo uses the same public asset packs shown in the course videos:

- Warrior character: Clembod, [Warrior Free Animation Set](https://clembod.itch.io/warrior-free-animation-set)
- Castle environment: brullov, [2D Platformer Asset Pack - Castle of Despair](https://brullov.itch.io/2d-platformer-asset-pack-castle-of-despair)

The files are kept under `Assets/Resources/Chapter62Art/` with a `course_` prefix. Check the linked asset pages for the current license and attribution terms before redistributing a build or using the art commercially.
