## 🎯 本节目标
通过一个**独立的演示对象**实际练习继承：把通用功能（组件引用、地面检测等）从子类提取到 `Entity` 基类中，体会继承带来的代码复用与更清晰的代码结构。

> ⚠️ **重要说明**：从本节起**不再继续开发正式的 Player Controller**（原话：*we're not going to work on the player controller anymore*）。本节的 `Entity` 与其子类是**教学演示用的独立对象**（如新建空物体挂载 `Player_Demo` 脚本，也可视为将来 Skeleton 敌人的预演），**不改动现有已完成功能的正式 Player**。正式的角色架构将在后续「状态机」章节推倒重建。

## 🖥️ 操作步骤

### 1. 创建基类 Entity
首先，我们需要一个通用的父类，用于存放所有“实体”（如玩家、敌人）共有的属性和方法。

- 在 Project 窗口创建名为 `Entity` 的 C# 脚本。
- 采用与 [[023_基础_继承]] 统一的「属性 + Awake」结构：`rb`、`anim` 用只读属性暴露；检测点等字段用 `[SerializeField] protected` 修饰——子类可以直接访问，但外部类看不到。

![创建Entity脚本](../screenshots/024_new1.jpg)

```csharp
using UnityEngine;

public class Entity : MonoBehaviour
{
    public Rigidbody2D rb { get; private set; }
    public Animator anim { get; private set; }

    public int facingDir { get; private set; } = 1;
    public bool isGrounded { get; private set; }
    public bool isWallDetected { get; private set; }

    [Header("Collision")]
    [SerializeField] protected Transform groundCheck;
    [SerializeField] protected Transform wallCheck;
    [SerializeField] protected float groundCheckDistance;
    [SerializeField] protected float wallCheckDistance;
    [SerializeField] protected LayerMask whatIsGround;

    protected virtual void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        anim = GetComponent<Animator>();
    }

    public void SetVelocity(float _xVelocity, float _yVelocity)
    {
        rb.velocity = new Vector2(_xVelocity, _yVelocity);
    }

    public void Flip()
    {
        facingDir *= -1;
        transform.Rotate(0, 180, 0);
    }

    protected virtual void CollisionChecks()
    {
        isGrounded = Physics2D.Raycast(groundCheck.position, Vector2.down,
                                        groundCheckDistance, whatIsGround);
        isWallDetected = Physics2D.Raycast(wallCheck.position,
                        Vector2.right * facingDir, wallCheckDistance, whatIsGround);
    }
}
```

### 2. 新建演示子类实现继承
新建一个独立的演示物体（如 2D Object → Sprite → Square，命名 `Player_Demo`），再为它创建同名脚本。**注意：不要修改现有已完成的正式 Player 脚本**，本节只在这个演示对象上练习继承。

- 将 `public class Player_Demo : MonoBehaviour` 改为 `public class Player_Demo : Entity`。
- 用 `override` 重写父类标记了 `virtual` 的 `Awake`，并调用 `base.Awake()` 完成 `rb`/`anim` 的初始化。
- 子类可以直接访问 `Entity` 中 `public`/`protected` 的成员，例如 `isGrounded`、`CollisionChecks()`、`rb`。

![演示子类继承Entity](../screenshots/024_new2.jpg)

```csharp
using UnityEngine;

public class Player_Demo : Entity
{
    [Header("Move Info")]
    [SerializeField] private float moveSpeed = 8f;
    [SerializeField] private float jumpForce = 12f;

    protected override void Awake()
    {
        // 调用父类的 Awake，完成 rb / anim 的获取
        base.Awake();
    }

    private void Update()
    {
        // 直接调用从 Entity 继承来的 CollisionChecks()
        CollisionChecks();

        if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
        {
            Jump();
        }
    }

    public void Jump()
    {
        // 即使 isGrounded 定义在 Entity 中，子类也可以直接访问
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);
    }
}
```

在 Inspector 面板中为演示物体配置 `Entity` 所需的引用，运行验证继承是否生效。

- 为 `Player_Demo` 物体添加 `Rigidbody2D` 组件。
- 新建空子物体 `GroundCheck` 并移到脚底，拖到 `Entity` 的 `Ground Check` 槽位；再填好 `What Is Ground` 图层与检测距离。
- 运行后按空格：只有 `isGrounded` 为 `true` 时才会起跳——这些成员全部来自父类 `Entity`，演示脚本里并没有重新定义。

## 📝 核心要点

- **`protected` 访问修饰符**：介于 `public` 和 `private` 之间。它不允许外部类访问，但允许**子类**访问。
- **`virtual` 关键字**：在父类方法上标记，表示该方法“可以被子类重写”。
- **`override` 关键字**：在子类方法上标记，表示“我要重新定义父类的这个方法”。
- **`base.Method()`**：用于在子类中调用父类的原方法。如果重写了 `Update` 但没有调用 `base.Update()`，父类中的逻辑将不会执行。
- **继承的优势**：如果以后添加 `Enemy` 类，只需继承 `Entity` 即可直接获得 `Rigidbody2D` 引用和地面检测功能，无需重复编写代码。
