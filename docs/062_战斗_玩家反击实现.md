## 🎯 本节目标

接上玩家侧：**按 Q 进入弹反状态**，窗口期内命中敌人即弹反成功——播放成功招架动画、把敌人钉在原地，敌人自己会因 `CanBeStunned()` 切进眩晕态。

## 🖥️ 操作步骤

### 步骤 1：输入改为 Q 键

```csharp
// PlayerGroundedState.cs —— Update 中追加
if (Input.GetKeyDown(KeyCode.Q))
    stateMachine.ChangeState(player.counterAttackState);
```

同时在 `Player` 里注册状态（动画布尔名就叫 `counterAttack`，基类的 `Enter/Exit` 会自动开关它）：

```csharp
// Player.cs
public PlayerCounterAttackState counterAttackState { get; private set; }

// Awake 中
counterAttackState = new PlayerCounterAttackState(this, stateMachine, "counterAttack");
```

> 🔧 若 `attackCheck`、`attackCheckRadius` 在 Player 中是 `private`，改成 `public`（或加属性暴露），状态脚本才能访问。

### 步骤 2：两个反击动画 clip 配置

- **PlayerCounterAttack**（弹反前摇）：从 Warrior 图集选一帧持械格挡姿势，做成**单帧 clip**——单帧定格就是"举剑等弹反"的架势。
- **PlayerSuccessfulCounterattack**（弹反成功）：从 `Warrior_Sheet_Effect` 招架特效帧生成 clip，**Sample Rate 设 20** 拉快节奏，打出一记干脆的反击斩；末尾 Add Event → `AnimationTrigger ()`，让 `triggerCalled` 收尾退出。

![制作成功反击动画](../screenshots/062_1.jpg)

Animator 参数与过渡：

1. 添加 **Bool 参数 `counterAttack`** 和 **Bool 参数 `successfulCounterAttack`**；
2. idle $\rightarrow$ CounterAttack：条件 `counterAttack = true`，无 Exit Time；
3. CounterAttack $\rightarrow$ successfulCounterAttack：条件 `successfulCounterAttack = true`，无 Exit Time；
4. 两个 clip 回到 idle：条件对应布尔为 `false`。

### 步骤 3：PlayerCounterAttackState 完整实现

```csharp
using UnityEngine;

public class PlayerCounterAttackState : PlayerState
{
    public PlayerCounterAttackState(Player _player, PlayerStateMachine _stateMachine,
                                    string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();                 // 自动 SetBool("counterAttack", true)

        stateTimer = 10f;             // 反击窗口期：比前摇动画长即可
        player.SetZeroVelocity();     // 弹反期间站桩防移动
    }

    public override void Update()
    {
        base.Update();

        // 窗口期内再按 Q：尝试弹反
        if (Input.GetKeyDown(KeyCode.Q))
        {
            Collider2D[] colliders = Physics2D.OverlapCircleAll(
                player.attackCheck.position, player.attackCheckRadius);

            foreach (var hit in colliders)
            {
                Enemy enemy = hit.GetComponent<Enemy>();

                if (enemy != null && enemy.CanBeStunned())
                {
                    stateTimer = 10f; // 重置计时，覆盖成功反击动画时长（以字幕为准）
                    player.anim.SetBool("successfulCounterAttack", true);
                    enemy.SetZeroVelocity();   // 敌人被钉住，随后自行进入眩晕态
                }
            }
        }

        if (stateTimer < 0 || triggerCalled)
            stateMachine.ChangeState(player.idleState);
    }

    public override void Exit()
    {
        base.Exit();   // 自动把 "counterAttack" 置回 false

        player.anim.SetBool("successfulCounterAttack", false);
    }
}
```

> 💡 **注意分工**：成功后我们**不手动改敌人的状态**——`enemy.CanBeStunned()` 内部已经把敌人切进 `stunnedState`。玩家侧只负责"问一句 + 给自己的反馈"，这就是上一节那个关键句的作用。
>
> ⚠️ 若 `SetZeroVelocity` 是 `protected`，把它放开成 `public`（或直接清空对方 `rb.velocity`），否则玩家侧调用编译不过。

## 📝 核心要点

```
弹反全链路：
  敌人攻击前摇 → OpenCounterAttackWindow()（061）
    → 头顶红方块亮起 / canBeStunned = true
  玩家按 Q → counterAttackState（站桩等待）
    → 再按 Q 命中 → enemy.CanBeStunned()
      → true：成功动画 + 敌人被钉住 → 敌人自动进眩晕
      → false：窗口没开，白按

计时器妙用：
  Enter 存 10f 当"窗口期"
  成功瞬间重置 10f 盖住成功动画时长
  归零或 triggerCalled → 回 idle
```
