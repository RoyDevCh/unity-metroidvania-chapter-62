# 敌人攻击

## 🎯 本节目标
在 `EnemySkeleton` 中通过 `override` 扩展基类的碰撞检测，用 `Physics2D.Raycast` 检测玩家：看到玩家后加速追击，进入攻击距离后停下并发起攻击（本节先用 `Debug.Log` 占位，真正的伤害在后续战斗章节接入）。

## 🖥️ 操作步骤

### 1. 为什么写在 EnemySkeleton 里？

玩家检测只有敌人才需要（玩家总不能检测自己），所以这段逻辑不放 `Entity` 基类，而是写在继承链 `Entity → Enemy → EnemySkeleton` 的最下层，通过 `override CollisionChecks()` 在基类检测的基础上**追加**功能。

![变量与override](../screenshots/026_new1.jpg)

### 2. 玩家检测变量

```csharp
[Header("Player Detection")]
[SerializeField] private float playerCheckDistance; // 检测距离
[SerializeField] private LayerMask whatIsPlayer;    // 只检测 Player 层

private RaycastHit2D isPlayerDetected; // 这次不用 bool，用 RaycastHit2D 保存更多信息
private bool isAttacking;              // 是否处于"停下攻击"的状态
```

**解释：** `Physics2D.Raycast` 返回 `RaycastHit2D`，除了"有没有打到"，还携带 `distance`（距离）、`collider`（打到了谁）等信息，比单纯的布尔检测灵活得多。讲师还借这次重命名演示了 `Ctrl + R, R` 快捷键（Rider / VS 均支持），可一次性重命名整个脚本中的同名变量。

### 3. override CollisionChecks：检测 + 追击 / 攻击判断

```csharp
protected override void CollisionChecks()
{
    base.CollisionChecks(); // 先执行 Entity 的地面 / 墙检测

    // 从自身位置沿朝向发射射线，只检测 Player 层
    isPlayerDetected = Physics2D.Raycast(transform.position, Vector2.right,
                                         playerCheckDistance * facingDir, whatIsPlayer);

    if (isPlayerDetected)
    {
        if (isPlayerDetected.distance > 1)
        {
            // 离得还远：加速追过去
            Debug.Log("I see the player");
            isAttacking = false;
        }
        else
        {
            // 进入攻击距离：停下攻击（暂用日志占位，真实伤害后续章节接入）
            Debug.Log("ATTACK: " + isPlayerDetected.collider.gameObject.name);
            isAttacking = true;
        }
    }
    else
    {
        isAttacking = false;
    }
}
```

**两个易错点：**

- 访问修饰符要和基类一致：`Entity.CollisionChecks()` 是 `protected virtual`，这里必须写 `protected override`；写成 `public override` 无法通过编译。
- 射线长度 `playerCheckDistance` 要乘上 `facingDir`，这样敌人 `Flip` 掉头后，检测方向才会跟着翻转。

![射线检测代码](../screenshots/026_new2.jpg)

### 4. 覆盖 Movement：攻击时停下，追击时加速

覆盖上一节 `Enemy.Movement()`，加上"攻击就停下、看见玩家就加速"的判断（讲师原话：这段代码有点糙，但足以演示思路）：

```csharp
protected override void Movement()
{
    if (isAttacking)
    {
        return; // 正在攻击：原地停下
    }

    // 检测到玩家但还没进入攻击距离时加速追击，否则按正常巡逻速度移动
    float _currentSpeed = isPlayerDetected ? moveSpeed * 1.5f : moveSpeed;
    rb.velocity = new Vector2(facingDir * _currentSpeed, rb.velocity.y);
}
```

### 5. 用 Gizmos 可视化检测射线

讲师还重写了 `OnDrawGizmos`，把检测范围画成一条蓝线。我们的 `Entity` 版本没有提供虚的 Gizmos 方法，直接写成普通的 Unity 消息方法即可——引擎会自动调用，**不需要** `override`：

```csharp
private void OnDrawGizmos()
{
    Gizmos.color = Color.blue;
    Gizmos.DrawLine(transform.position,
        new Vector3(transform.position.x + playerCheckDistance * facingDir,
                    transform.position.y));
}
```

![Gizmos与攻击分支](../screenshots/026_new3.jpg)

### 6. Unity 编辑器配置

1. **创建 Layer**：Inspector 右上角图层下拉 → `Add Layer`，新增一个名为 `Player` 的层。
2. **分配 Layer**：选中 Player 物体，把它的 Layer 设为 `Player`。
3. **配置敌人**：在 `Enemy_Skeleton` 组件中，将 `What Is Player` 选择为 `Player` 层，`Player Check Distance` 设置为 `4`。
4. **运行验证**：骷髅正常巡逻 → 玩家进入范围后 Console 刷出 `I see the player` 并加速追击 → 靠近后停下并输出 `ATTACK: Player`。

## 💻 完整代码

```csharp
using UnityEngine;

public class EnemySkeleton : Enemy
{
    [Header("Player Detection")]
    [SerializeField] private float playerCheckDistance;
    [SerializeField] private LayerMask whatIsPlayer;

    private RaycastHit2D isPlayerDetected;
    private bool isAttacking;

    protected override void CollisionChecks()
    {
        base.CollisionChecks();

        isPlayerDetected = Physics2D.Raycast(transform.position, Vector2.right,
                                             playerCheckDistance * facingDir, whatIsPlayer);

        if (isPlayerDetected)
        {
            if (isPlayerDetected.distance > 1)
            {
                Debug.Log("I see the player");
                isAttacking = false;
            }
            else
            {
                Debug.Log("ATTACK: " + isPlayerDetected.collider.gameObject.name);
                isAttacking = true;
            }
        }
        else
        {
            isAttacking = false;
        }
    }

    protected override void Movement()
    {
        if (isAttacking)
        {
            return;
        }

        float _currentSpeed = isPlayerDetected ? moveSpeed * 1.5f : moveSpeed;
        rb.velocity = new Vector2(facingDir * _currentSpeed, rb.velocity.y);
    }

    private void OnDrawGizmos()
    {
        Gizmos.color = Color.blue;
        Gizmos.DrawLine(transform.position,
            new Vector3(transform.position.x + playerCheckDistance * facingDir,
                        transform.position.y));
    }
}
```

## 📝 核心要点

- **继承链完整**：`Entity → Enemy → EnemySkeleton`。"所有实体都要"的逻辑放 `Entity`，"只有敌人要"的放 `Enemy`，"只有骷髅要"的放 `EnemySkeleton`，各层各司其职。
- **Override 机制**：先 `base.CollisionChecks()` 保留基类检测，再追加骷髅特有的玩家检测——不改基类一行代码就能扩展行为。
- **签名要匹配**：基类是 `protected virtual`，子类必须写 `protected override`，访问修饰符不能改。
- **Raycast2D 灵活性**：`RaycastHit2D` 一个变量同时给出命中与否、`distance` 和 `collider`，可以据此做距离分层行为，甚至通过 `collider.GetComponent()` 拿到对方脚本调用方法。
- **LayerMask 优化**：不过滤的话射线可能打到自己、地面或墙；配合乘 `facingDir`，掉头后检测方向自动翻转。
- **攻击是占位实现**：目前攻击只是 `Debug.Log` + 原地停下；真正的攻击动画与伤害结算（`CharacterStats` 属性系统）将在主课程的战斗章节接入。
