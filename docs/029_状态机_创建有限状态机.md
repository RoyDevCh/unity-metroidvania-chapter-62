## 🎯 本节目标

将 Player.cs 中的 if/else 状态判断重构为**有限状态机**模式，让每个状态（Idle、Move、Jump 等）有自己独立的类。

> 🔑 为什么要重构？一个大 Player.cs 写所有逻辑会越来越臃肿。FSM 让每个状态独立，代码可维护。

```

```

---

### 步骤 2：状态基类 PlayerState

```csharp
public class PlayerState
{
    protected PlayerStateMachine stateMachine;
    protected Player player;
    protected string animBoolName;

    public PlayerState(Player _player, PlayerStateMachine _stateMachine,
                        string _animBoolName)
    {
        player = _player;
        stateMachine = _stateMachine;
        animBoolName = _animBoolName;
    }

    public virtual void Enter()
    {
        player.anim.SetBool(animBoolName, true);
    }

    public virtual void Update()
    {
    }

    public virtual void Exit()
    {
        player.anim.SetBool(animBoolName, false);
    }
}
```

> 💡 基类的 `Enter`/`Exit` 自动处理 Animator 参数——子状态只需写自己的逻辑。

### 步骤 3：状态机 PlayerStateMachine

```csharp
public class PlayerStateMachine
{
    public PlayerState currentState { get; private set; }

    public void Initialize(PlayerState _startState)
    {
        currentState = _startState;
        currentState.Enter();
    }

    public void ChangeState(PlayerState _newState)
    {
        currentState.Exit();
        currentState = _newState;
        currentState.Enter();
    }
}
```

### 步骤 4：具体状态（以 Idle 为例）

```csharp
public class PlayerIdleState : PlayerState
{
    public PlayerIdleState(Player _player, PlayerStateMachine _stateMachine,
                            string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Update()
    {
        base.Update();

        // 有水平输入 → 切换到移动状态
        if (player.xInput != 0 && !player.isBusy)
            stateMachine.ChangeState(player.moveState);

        // 按跳跃 → 切换到跳跃状态
        if (Input.GetKeyDown(KeyCode.Space) && player.isGrounded)
            stateMachine.ChangeState(player.jumpState);
    }
}
```

### 步骤 5：Player.cs 持有状态机

```csharp
public class Player : MonoBehaviour
{
    public PlayerStateMachine stateMachine { get; private set; }
    public PlayerIdleState idleState { get; private set; }
    public PlayerMoveState moveState { get; private set; }
    public PlayerJumpState jumpState { get; private set; }

    // ... 其他组件和变量 ...

    void Awake()
    {
        stateMachine = new PlayerStateMachine();
        idleState = new PlayerIdleState(this, stateMachine, "Idle");
        moveState = new PlayerMoveState(this, stateMachine, "Move");
        jumpState = new PlayerJumpState(this, stateMachine, "Jump");
    }

    void Start()
    {
        stateMachine.Initialize(idleState);
    }

    void Update()
    {
        stateMachine.currentState.Update();
    }
}
```

## 📝 核心要点

```
FSM 架构：

PlayerState (基类)
  ├── Enter() → 设置 Animator 参数 = true
  ├── Update() → 检查输入，决定切换哪个状态
  └── Exit()  → 设置 Animator 参数 = false

PlayerStateMachine
  ├── currentState → 当前活跃状态
  ├── Initialize() → 设置初始状态
  └── ChangeState() → Exit旧 → Enter新

Player
  └── 持有所有状态实例 + stateMachine
     Update() → currentState.Update()

状态切换：
  IdleState.Update() 检测到输入
    → stateMachine.ChangeState(moveState)
      → idleState.Exit()  (anim "Idle" = false)
      → moveState.Enter() (anim "Move" = true)
```
