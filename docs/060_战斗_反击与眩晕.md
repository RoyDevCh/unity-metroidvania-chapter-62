## 🎯 本节目标

给骷髅敌人新增一个 **眩晕状态 `SkeletonStunnedState`**：被玩家成功弹反后进入眩晕、向后踉跄、身体红闪；同时给 `EntityFX` 补上红闪特效方法。本节先把"挨打的一方"准备好，反击窗口（061）和玩家按键弹反（062）随后接入。

## 🖥️ 操作步骤

### 步骤 1：Enemy 补眩晕参数

```csharp
// Enemy.cs
[Header("Stun Info")]
public float stunDuration;                    // 眩晕持续时长
[SerializeField] protected Vector2 stunDirection; // 眩晕位移方向（x=1,y=0 即沿朝向反方向退）
```

![创建 SkeletonStunnedState 脚本](../screenshots/060_1.jpg)

### 步骤 2：创建 SkeletonStunnedState

新建脚本继承 `EnemyState`：构造函数调用基类的三参构造（敌人基类、状态机、动画布尔名），再额外接收一个 `EnemySkeleton` 引用方便访问子类成员。

```csharp
using UnityEngine;

public class SkeletonStunnedState : EnemyState
{
    private EnemySkeleton enemy;
    private readonly EntityFX fx;

    public SkeletonStunnedState(Enemy _enemyBase, EnemyStateMachine _stateMachine,
                                string _animBoolName, EnemySkeleton _enemy)
        : base(_enemyBase, _stateMachine, _animBoolName)
    {
        this.enemy = _enemy;
        this.fx = _enemy.GetComponent<EntityFX>();
    }

    public override void Enter()
    {
        base.Enter();

        anim.SetBool("stunned", true);

        stateTimer = enemy.stunDuration;

        // 眩晕位移直接写 rb.velocity，不走 SetVelocity：
        // SetVelocity 会经过 FlipController 按当前朝向翻转，
        // "向后退"会被翻成"向面朝的方向冲"
        rb.velocity = new Vector2(-enemy.facingDir * enemy.stunDirection.x, enemy.stunDirection.y);

        fx?.StartRedFlash();
    }

    public override void Exit()
    {
        base.Exit();

        anim.SetBool("stunned", false);
        fx?.cancelColorChange();
    }

    public override void Update()
    {
        base.Update();

        if (stateTimer < 0)
            stateMachine.ChangeState(enemy.idleState);
    }
}
```

> 💡 `anim` 和 `rb` 是状态基类里缓存的引用（进入状态时从实体身上取）；若你的 `EnemyState` 还没有这两个成员，照 `PlayerState` 的做法补上即可，或改写成 `enemy.anim` / `enemy.rb`。
>
> ⏱️ 退出时机以字幕为准：`stateTimer < 0` 就离开眩晕回到待机；眩晕期间再次被攻击时同样按字幕处理切回战斗/待机流程（视频演示用的是 `idleState`）。

### 步骤 3：敌人 stun 动画与 Animator 配置

1. 从骷髅图集中挑一张"被击晕"的表情帧，做成**单帧动画 clip**（如 `skeletonStun`）——单帧定格正是眩晕呆滞感的来源。
2. 打开骷髅的 Animator（`Skeleton_AC`），添加 **Bool 参数 `stunned`**。
3. 待机状态 $\rightarrow$ 眩晕 clip：条件 `stunned = true`，取消 Has Exit Time、Duration 0。
4. 眩晕 clip $\rightarrow$ 待机：条件 `stunned = false`，取消 Has Exit Time。

状态的 `Enter/Exit` 开关这个布尔，Animator 就会在眩晕姿势和正常动画之间切换。

### 步骤 4：EntityFX 补红闪方法

眩晕期间敌人要不停红闪示警。在 `EntityFX.cs` 里追加三个方法（`sr` 就是该脚本已有的 `SpriteRenderer` 引用）：

```csharp
// EntityFX.cs 追加
public void StartRedFlash()
{
    CancelInvoke(nameof(RedColorBlink));
    InvokeRepeating("RedColorBlink", 0, .1f);   // 立刻开始，每 0.1 秒闪一次
}

private void RedColorBlink()
{
    sr.color = sr.color != Color.white ? Color.white : Color.red; // 红/白来回切
}

public void cancelColorChange()
{
    CancelInvoke("RedColorBlink");
    sr.color = Color.white;
}
```

**解释：**
- `StartRedFlash` 用 `InvokeRepeating` 周期性在红色和白色之间切换精灵颜色，形成持续的警示闪烁；
- `cancelColorChange()` 负责收尾：停止重复调用并把颜色复位为纯白；死亡透明效果应由死亡流程单独处理。

### 步骤 5：在 EnemySkeleton 上注册眩晕状态

```csharp
// EnemySkeleton.cs
public SkeletonStunnedState stunnedState { get; private set; }

protected override void Awake()
{
    base.Awake();

    stunnedState = new SkeletonStunnedState(this, stateMachine, "stunned", this);
}

protected override EnemyState GetStunnedState()
{
    return stunnedState;
}
```

注意动画布尔名 `"stunned"` 要与 Animator 参数、状态代码里的字符串完全一致。

### 步骤 6：Inspector 测试值

选中骷髅，在 Enemy 组件的 **Stun Info** 区块设置：

- **Stun Duration = 1**（视频演示用 1 秒方便快速观察效果，正式手感可以调到 3–4 秒）；
- **Stun Direction：x = 1，y = 0**。

![眩晕时长 Inspector 配置](../screenshots/060_2.jpg)

> **工程修复**：`stunnedState` 只属于 `EnemySkeleton`，不能在 `Enemy` 基类中直接访问。本节通过 `GetStunnedState()` 虚方法让基类处理通用窗口逻辑、子类提供具体状态；如果以后有别的敌人也支持眩晕，只需在该敌人子类覆盖这个方法。

## 📝 核心要点

```
眩晕状态三件事（Enter）：
  开动画布尔  anim.SetBool("stunned", true)
  定时长      stateTimer = enemy.stunDuration
  后退+红闪   rb.velocity 直设 / fx.StartRedFlash()

为什么不用 SetVelocity？
  它经 FlipController 按朝向翻转 → 后退变前冲
  眩晕位移必须无视翻转 → 直接写 rb.velocity

红闪实现：InvokeRepeating 每 0.1s 红白互换
  收尾必须 CancelInvoke + 复位颜色（cancelColorChange）

触发链路预告：
  062 玩家 Q 键命中 → enemy.CanBeStunned()
    → ChangeState(stunnedState) → 本节状态接管
```
