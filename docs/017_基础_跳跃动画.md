## 🎯 本节目标

添加跳跃和下落动画。本节的核心是 **Blend Tree（混合树）**：把 Jump/Fall 两个动画放进一棵混合树，用 `yVelocity` 参数按垂直速度自动平滑混合；落地后由 `isGrounded` 切回 Idle。

> **课程阶段核对**：视频先做 `Any State -> playerJump` 的中间方案，再在同一节替换为 `JumpFall` Blend Tree。课程截图中的节点布局可能仍处于前一阶段；本页的 Blend Tree、`yVelocity` 和最终过渡列表才是视频结束时应保留的配置。Gravity Scale、jumpForce、moveSpeed 都是在 Inspector 调参，完整代码里的默认值只是整合参考。

---

## 🖥️ 操作步骤

### 步骤 1：创建跳跃和下落动画片段

1. 选中 Player → Animation 窗口 → Create New Clip，保存到 `Animations` 文件夹，命名 `playerJump`
2. 从 Graphics 的精灵图中把跳跃帧（第 42~43 帧）拖入时间线，Sample Rate 设为 10
3. 再创建 `playerFall`，拖入下落帧（第 46~48 帧），Sample Rate 同样设为 10

![Jump动画](../screenshots/017_jump_anim.jpg)

---

### 步骤 2：创建 Blend Tree 混合 Jump/Fall

不给 Jump/Fall 分别设置过渡，而是用一个 **Blend Tree** 让它们按速度自动混合：

1. Animator 窗口 → 右键 → **Create State → From New Blend Tree**（创建时会自动生成一个 Float 参数）
2. 把新状态重命名为 `JumpFall`，并把自动生成的参数重命名为 `yVelocity`
3. 双击进入 `JumpFall`，在 Motion 列表添加两个动作：
   - 第 1 个：`playerFall` → 取消勾选 **Automate Thresholds** 后，阈值设为 `-1`
   - 第 2 个：`playerJump` → 阈值保持默认 `0`
4. 在 Inspector 中确认该 Blend Tree 的 **Blend Parameter** 为 `yVelocity`

原理：`yVelocity > 0`（上升）偏向 `playerJump`，`yVelocity < 0`（下落）偏向 `playerFall`——两个动画随垂直速度自动平滑切换，无需手动做 Jump→Fall 过渡。

![Animator状态机](../screenshots/017_animator.jpg)

> 这张图用于定位 Animator 窗口，不应单独决定最终节点布局。若仍留有旧的 `Any State -> playerJump` 过渡，按视频后半段把它替换为通向 `JumpFall` 的最终过渡。

---

### 步骤 3：设置状态机过渡

从 `playerIdle`（以及 `playerMove`）拖一条过渡到 `JumpFall`：
- Condition: `isGrounded == false`
- Has Exit Time: ❌
- Transition Duration: 0

从 `JumpFall` 拖一条过渡回 `playerIdle`：
- Condition: `isGrounded == true`（落地先回 Idle，之后由 `isMoving` 自动接回 Move）
- Has Exit Time: ❌
- Transition Duration: 0

> ⚠️ 之前若做过「Any State → playerJump」的旧方案，请删掉——它已被 Blend Tree 方案取代。
>
> 💡 若跳跃动画只播第一帧或无法重复触发，到对应过渡的 Settings 里检查 **Can Transition To Self**。

---

### 步骤 4：脚本中更新动画参数

`isGrounded` 所需的 GroundCheck 射线检测与 Layer 配置已在 [[016_基础_2D 碰撞检测]] 完成，本节直接沿用，不重复实现。只需在 Player 脚本的 `AnimatorControllers()` 函数中为两个参数赋值：

```csharp
anim.SetFloat("yVelocity", rb.velocity.y);
anim.SetBool("isGrounded", isGrounded);
```

## 💻 完整代码

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    [SerializeField] private float moveSpeed = 8f;
    [SerializeField] private float jumpForce = 12f;

    [Header("Collision")]
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float groundCheckDistance;
    [SerializeField] private LayerMask whatIsGround;

    private Rigidbody2D rb;
    private Animator anim;
    private float xInput;
    private bool isGrounded;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        anim = GetComponentInChildren<Animator>();
    }

    void Update()
    {
        // 地面检测（016 节已实现）
        isGrounded = Physics2D.Raycast(groundCheck.position, Vector2.down,
                                         groundCheckDistance, whatIsGround);

        Movement();
        CheckInput();

        // 翻转
        if (xInput < 0) transform.localScale = new Vector3(-1, 1, 1);
        else if (xInput > 0) transform.localScale = new Vector3(1, 1, 1);

        AnimatorControllers();
    }

    private void CheckInput()
    {
        xInput = Input.GetAxisRaw("Horizontal");

        if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
        {
            Jump();
        }
    }

    private void Movement()
    {
        rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);
    }

    private void Jump()
    {
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);
    }

    private void AnimatorControllers()
    {
        // yVelocity 驱动 Blend Tree 在 Jump/Fall 之间平滑混合
        anim.SetFloat("yVelocity", rb.velocity.y);
        anim.SetBool("isGrounded", isGrounded);
    }
}
```

> ✅ 结构沿用 014 节的重构结果（`Movement / CheckInput / Jump / AnimatorControllers`）；跳跃条件带 `&& isGrounded`，不会无限连跳。

## 📝 核心要点

```
跳跃动画状态流：
  Idle/Move → JumpFall (isGrounded = false)
  JumpFall 内部按 yVelocity 混合：
    yVelocity > 0 → playerJump（上升）
    yVelocity < 0 → playerFall（下落）
  JumpFall → Idle (isGrounded = true)

Blend Tree：
  参数 yVelocity(Float)，每帧 anim.SetFloat("yVelocity", rb.velocity.y)
  一棵混合树取代了 Any State + Jump/Fall 各自过渡的旧方案

手感数值：
  Gravity Scale 3.5 / jumpForce 12 / moveSpeed 8
```
