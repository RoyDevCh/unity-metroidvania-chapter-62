## 🎯 本节目标

用 `comboCounter` 串起三段攻击动画：连击窗口内点击逐段递进，超时或打完第三段自动归零。

## 🖥️ 操作步骤

### 步骤 1：连击计数字段

```csharp
// PlayerPrimaryAttack.cs 类内新增
private int comboCounter;

private float lastTimeAttacked;      // 上一次攻击完成的时间点
private float comboWindow = 2;       // 连击窗口：超过 2 秒未接招则重置
```

### 步骤 2：Enter —— 决定本段是第几击

```csharp
public override void Enter()
{
    base.Enter();

    // 打完第三段，或距上次攻击超过窗口 → 回到第一段
    if (comboCounter > 2 || Time.time >= lastTimeAttacked + comboWindow)
        comboCounter = 0;

    // 告诉 Animator 播哪一段
    player.anim.SetInteger("ComboCounter", comboCounter);
}
```

先用 `Debug.Log(comboCounter)` 验证：连续点击输出 0、1、2、0、1、2……原地等两秒再点，又从 0 开始。

### 步骤 3：Exit —— 完成一段才计数

```csharp
public override void Exit()
{
    base.Exit();

    comboCounter++;                 // 这一段演完了，下一段是下一击
    lastTimeAttacked = Time.time;   // 记录完成时刻，供窗口判断
}
```

> 💡 计数放在 **Exit** 而不是 Enter：只有真正完整打完一段，才有资格进入下一段。

### 步骤 4：Animator 改造为子状态机

- 参数面板添加 **Int** 参数 `ComboCounter`（当前参数总表：`Idle`/`Move`/`Jump`/`Dash`/`WallSlide`/`Attack` 为 Bool，`yVelocity` 为 Float，`ComboCounter` 为 Int）。
- 右键 $\rightarrow$ **Create Sub-State Machine**，命名 `PrimaryAttack`，双击进入：
  - 新建空状态 `Empty`；
  - 把 Project 里的 `playerAttack1/2/3` 三个 clip 拖进来；
  - `Empty` $\rightarrow$ 三段攻击各连一条过渡，条件分别是 **ComboCounter equals 0 / 1 / 2**，三条全部 **Has Exit Time ❌、Duration 0**；
  - 三段攻击各自 $\rightarrow$ **Exit**：条件 `Attack = false`，**勾选 Has Exit Time**（默认值）、Duration 0；
- 回到 Base Layer：`Entry` $\rightarrow$ `PrimaryAttack` 子状态，条件 `Attack = true`；把之前直接挂在 Base Layer 的 `playerAttack1` 及其旧过渡删掉。

- `playerAttack2`、`playerAttack3` 各自在末尾 **Add Event** $\rightarrow$ Function 选 `AnimationTrigger ()`（039 的接线）。

## 💻 完整代码

### PlayerPrimaryAttack.cs（040 版）

```csharp
using UnityEngine;

public class PlayerPrimaryAttack : PlayerState
{
    private int comboCounter;

    private float lastTimeAttacked;
    private float comboWindow = 2;

    public PlayerPrimaryAttack(Player _player, PlayerStateMachine _stateMachine,
                                string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();

        if (comboCounter > 2 || Time.time >= lastTimeAttacked + comboWindow)
            comboCounter = 0;

        player.anim.SetInteger("ComboCounter", comboCounter);
    }

    public override void Update()
    {
        base.Update();

        if (triggerCalled)
            stateMachine.ChangeState(player.idleState);
    }

    public override void Exit()
    {
        base.Exit();

        comboCounter++;
        lastTimeAttacked = Time.time;
    }
}
```

### 连击流转

```
Enter: 超三段或超 2s 窗口 → comboCounter=0
       SetInteger("ComboCounter") → Animator 播对应段
Update: triggerCalled（动画事件）→ ChangeState(idleState)
Exit:   comboCounter++ 且记录 lastTimeAttacked
```

> ⏭️ 预告：此时攻击中还能自由移动、也没有打击位移——**041** 节加入 `attackMovement` 数组位移、`stateTimer` 惯性停顿与 `isBusy` 锁定；**042** 节改类名并支持攻击中变向。

## 📝 核心要点

```
三段连击：
  comboCounter 0/1/2 ↔ 动画 Attack1/2/3（Int 参数驱动子状态机）
  重置条件（满足其一即归零）：
    ① comboCounter > 2     （三段打满）
    ② Time.time >= lastTimeAttacked + comboWindow（超过 2s 没接招）

计数时机：Exit 才 ++ —— 完整播完一段才算数
窗口判断用 Time.time 时间戳，不占用计时器
```
