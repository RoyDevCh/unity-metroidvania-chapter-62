## 课程原版（第 58 节）

### 1. 添加击退数据

在 `Entity` 的序列化字段区域加入：

```csharp
[Header("Knockback Info")]
[SerializeField] protected Vector2 knockbackDirection;
[SerializeField] protected float knockbackDuration;
protected bool isKnocked;
```

`knockbackDirection.x` 是水平击退力度，`y` 是向上速度。名称在这一节略容易误解，但它还是一个 `Vector2`，不是 `int` 或 `Transform`。

![字段的课程截图](../screenshots/058_new1.jpg)

### 2. 在现有伤害入口启动协程

视频在已有的 `Damage()` 内增加下面这一行。保留这个方法里此前已有的闪白、日志或受伤处理，不要用一个空方法覆盖它：

```csharp
StartCoroutine("HitKnockback");
```

最终截图中的入口顺序为“闪白 -> 启动 `HitKnockback` -> 原有日志”。字符串协程是课程写法；后续工程可以改为 `StartCoroutine(HitKnockback())`，但不能同时保留两次启动。

### 3. 添加击退协程

```csharp
protected virtual IEnumerator HitKnockback()
{
    isKnocked = true;

    rb.velocity = new Vector2(
        knockbackDirection.x * -facingDir,
        knockbackDirection.y);

    yield return new WaitForSeconds(knockbackDuration);

    isKnocked = false;
}
```

协程直接写 `rb.velocity`，不能改成调用 `SetVelocity()`：后者会被下一步的 `isKnocked` 锁拦截。`-facingDir` 的含义是受击者朝右时向左飞、朝左时向右飞；这正是第 162 节要改善的局限。

![课程最终的 Damage、协程和速度锁](../screenshots/058_new3.jpg)

### 4. 同时锁住两个常规速度入口

课程先在 `SetVelocity()` 里加锁，实际运行后发现攻击状态中的 `SetZeroVelocity()` 会立刻抹掉击退，所以两个入口都要加：

```csharp
public void SetZeroVelocity()
{
    if (isKnocked)
        return;

    rb.velocity = Vector2.zero;
}

public void SetVelocity(float xVelocity, float yVelocity)
{
    if (isKnocked)
        return;

    rb.velocity = new Vector2(xVelocity, yVelocity);
    FlipController(xVelocity);
}
```

## 到第 162 节的迁移

第 162 节才进行以下替换；不要在本节同时声明两个 `knockbackDirection`：

| 第 58 节 | 第 162 节之后 |
|---|---|
| `Vector2 knockbackDirection` 表示力度 | 重命名为 `Vector2 knockbackPower` |
| `-facingDir` 决定水平朝向 | 改为由伤害来源推导的整数方向 |
| `Damage()` 中启动击退 | 后期统一为 `DamageImpact()` 入口 |

后续的完整迁移见 [[162_优化_击退方向改进]]；最终可复制接口以 [[!!CANONICAL_API]] 为准。
