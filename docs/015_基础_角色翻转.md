## 🎯 本节目标

让角色根据移动方向自动翻转面朝左/右。

---

## 🖥️ 操作步骤

### 步骤 1：问题现象

当前角色向左移动时，面朝不变——角色"倒退"走路：

![翻转前](../screenshots/015_before.jpg)

---

### 步骤 2：添加翻转逻辑

在 `Player.cs` 的 `Update()` 末尾加入翻转代码：

```csharp
void Update()
{
    xInput = Input.GetAxisRaw("Horizontal");
    rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);

    // 跳跃代码...

    // 翻转角色
    if (xInput < 0)
        transform.Rotate(0, 180, 0);   // 面朝左
    else if (xInput > 0)
        transform.Rotate(0, 0, 0);      // 面朝右
}
```

> ⚠️ `Rotate` 会有问题——每帧都旋转会累积。改用直接设置 scale 更好：

```csharp
void Update()
{
    xInput = Input.GetAxisRaw("Horizontal");
    rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);

    // 翻转角色——通过修改 scale 的 x 值
    if (xInput < 0)
        transform.localScale = new Vector3(-1, 1, 1);  // 翻转
    else if (xInput > 0)
        transform.localScale = new Vector3(1, 1, 1);   // 正常
}
```

## 📝 核心要点

```
翻转角色两种方式：
  1. transform.Rotate(0, 180, 0) → ❌ 每帧累积旋转
  2. transform.localScale = new Vector3(-1, 1, 1) → ✅ 直接设缩放

面朝右: localScale.x = 1
面朝左: localScale.x = -1
```
