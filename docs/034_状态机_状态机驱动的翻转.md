## 🎯 本节目标

实现角色左右翻转：`facingDir` 记录朝向数值，`Flip()` 执行翻转，`FlipController()` 决定"何时翻"，并把它挂进 `SetVelocity()`，让所有状态的移动自动带翻转。

> **课程命名核对**：课程截图把 `FlipController` 的形参命名为 `_xVelocity`；旧版文档写 `_xInput`。形参名不改变行为，但本页以下代码采用课程命名，避免把“输入值”和“实际速度”混为一谈。

## 🖥️ 操作步骤

### 步骤 1：理解翻转原理

在 Scene 的 3D 视角下把角色绕 **Y 轴**旋转 180° 即为翻转——不只是视觉镜像，角色的局部坐标系也跟着反转，后续攻击、射线等方向性逻辑左右通吃。

![旋转Y轴演示](../screenshots/034_new1.jpg)

### 步骤 2：定义方向变量

```csharp
// Player.cs 顶部
// 1 表示面向右，-1 表示面向左；公开只读，各状态都能读
public int facingDir { get; private set; } = 1;

// 仅内部判断用的布尔开关
private bool facingRight = true;
```

### 步骤 3：编写 Flip()

```csharp
public void Flip()
{
    // 方向数值取反：1 ↔ -1
    facingDir = facingDir * -1;
    // 布尔开关同步切换
    facingRight = !facingRight;
    // 绕 Y 轴转 180° 完成视觉翻转
    transform.Rotate(0, 180, 0);
}
```

![代码定义](../screenshots/034_new2.jpg)

### 步骤 4：编写 FlipController()

先写一个直白版本：根据 X 轴的值判断"该不该翻"。参数既可传输入值、也可传速度值：

```csharp
public void FlipController(float _xVelocity)
{
    // 向右移动/输入，但面朝左 → 翻转
    if (_xVelocity > 0 && !facingRight)
        Flip();
    // 向左移动/输入，但面朝右 → 翻转
    else if (_xVelocity < 0 && facingRight)
        Flip();
}
```

### 步骤 5：挂进 SetVelocity() —— 不要放在 Update 里

视频先临时把 `FlipController(rb.velocity.x)` 放进 Player.Update 验证效果，随后**从 Update 中删除**，改为传参调用：哪个函数负责给速度，哪个函数顺带管翻转。

```csharp
public void SetVelocity(float _xVelocity, float _yVelocity)
{
    rb.velocity = new Vector2(_xVelocity, _yVelocity);
    FlipController(_xVelocity);   // ← 每次设速时自动校正朝向
}
```

这样某些特殊状态（如跳跃中禁止移动但仍想转身观察）可以选择不经过它，控制权在我们手里。

![调用位置与 Inspector](../screenshots/034_new3.jpg)

运行测试：左右跑动时角色正确转向，不再倒退着跑。

## 💻 完整代码

### Player.cs（翻转相关部分）

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    [Header("Move Info")]
    public float moveSpeed;

    public int facingDir { get; private set; } = 1;
    private bool facingRight = true;

    // ... stateMachine / states / anim / rb 等已有成员不变 ...

    public void SetVelocity(float _xVelocity, float _yVelocity)
    {
        rb.velocity = new Vector2(_xVelocity, _yVelocity);
        FlipController(_xVelocity);
    }

    public void Flip()
    {
        facingDir = facingDir * -1;
        facingRight = !facingRight;
        transform.Rotate(0, 180, 0);
    }

    public void FlipController(float _xVelocity)
    {
        if (_xVelocity > 0 && !facingRight)
            Flip();
        else if (_xVelocity < 0 && facingRight)
            Flip();
    }
}
```

> ⏳ 本节的墙检测 Gizmos 还只会画朝右一侧，这是正常的；有了 `facingDir` 之后，037 节的墙壁射线会用 `Vector2.right * facingDir` 自动跟随朝向。

## 📝 核心要点

- **Y 轴旋转**：`transform.Rotate(0, 180, 0)` 而不是 `localScale.x = -1`，子物体、碰撞体方向一并翻转。
- **三层分工**：`facingDir`（数据）$\rightarrow$ `Flip()`（执行）$\rightarrow$ `FlipController()`（决策），职责清晰可单独复用。
- **挂载点**：翻转跟着 `SetVelocity()` 走而不是常驻 Update——需要"移动但不转身"的状态天然被支持。
- **访问控制**：`{ get; private set; }` 保证只有 Player 自己能改朝向，状态只能读。
