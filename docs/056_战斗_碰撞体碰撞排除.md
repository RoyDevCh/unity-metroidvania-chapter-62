# 碰撞体碰撞排除

> **战斗** | 第 56/192 节 | [[055_战斗_攻击检测逻辑|⬅️ 攻击检测逻辑]] | [[057_战斗_受击特效|➡️ 受击特效]]

## 🎯 本节目标
通过配置 Unity 的 Layer Collision Matrix（层碰撞矩阵），实现玩家与敌人之间可以互相穿透，从而模拟参考游戏中灵活的战斗移动机制。

## 🖥️ 操作步骤

### 1. 为对象分配 Layer（层）
首先，我们需要为玩家和敌人定义独立的 Layer，以便在物理设置中对它们进行区分。

- 在 **Hierarchy** 窗口中选中 `Player` 对象。
- 在 **Inspector** 面板顶部的 `Layer` 下拉菜单中，选择 `Add Layer...`。
- 在 User Layer 列表中添加 `Player` 层，然后重新选中 `Player` 对象将其 Layer 设置为 `Player`。
- 对 `Enemy` 对象重复上述操作，为其创建并分配 `Enemy` 层。

![设置Layer](../screenshots/056_new1.jpg)

### 2. 打开物理 2D 设置
进入 Unity 的全局物理配置界面，调整碰撞规则。

- 点击顶部菜单栏的 `Edit` $\rightarrow$ `Project Settings`。
- 在左侧列表中选择 `Physics 2D`。

![打开Physics 2D](../screenshots/056_new2.jpg)

### 3. 配置层碰撞矩阵 (Layer Collision Matrix)
在物理设置界面中，通过矩阵勾选来决定哪些层之间会发生碰撞。

- 找到底部的 **Layer Collision Matrix** 区域。
- 寻找 `Player` 行与 `Enemy` 列的交汇点（或反之）。
- **取消勾选** 该交汇点的复选框。
- **解释**：取消勾选意味着 Unity 的物理引擎将忽略这两个层之间的碰撞检测，使它们能够互相穿过，而不会产生物理挤压或被挡住。

![配置碰撞矩阵](../screenshots/056_new3.jpg)

## 📝 核心要点
- **Layer (层)**：用于将游戏对象分组，是控制物理碰撞过滤的基础。
- **Layer Collision Matrix**：一个高效的全局开关，无需编写代码即可决定哪些类型的对象可以碰撞，哪些不能。
- **效果对比**：
    - **勾选状态**：`Collider2D` 之间会发生碰撞，玩家会被敌人挡住，甚至能站在敌人头上。
    - **取消勾选**：玩家可以自由穿过敌人，但依然能接收来自敌人的攻击触发（如果攻击是通过 Trigger 实现的）。
