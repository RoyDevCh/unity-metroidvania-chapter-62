## 🎯 本节目标

在攻击动画关键帧用 `OverlapCircleAll` 检测敌人，实现精确的攻击判定。

---

## 🖥️ 操作步骤

### 步骤 1：添加攻击检测点

1. Player 下方创建空子对象 → 命名 `AttackCheck`
2. 放在武器前方（手的位置偏上）
3. 在 Player 脚本中暴露：

```csharp
[Header("Attack Info")]
[SerializeField] private Transform attackCheck;
[SerializeField] private float attackCheckRadius = 0.8f;
```

4. 创建完成后，把 `AttackCheck` 子物体拖到 Player 的 `Attack Check` 字段上

![攻击检测点](../screenshots/055_a.jpg)

---

### 步骤 2：攻击检测方法

```csharp
// Player.cs
private void AttackTrigger()
{
    Collider2D[] colliders = Physics2D.OverlapCircleAll(attackCheck.position, attackCheckRadius);

    foreach (var hit in colliders)
    {
        if (hit.GetComponent<Enemy>() != null)
        {
            hit.GetComponent<Enemy>().Damage();
        }
    }
}
```

> 🔑 `AttackTrigger()` 由 Animation Event 在**武器挥到关键帧**时调用——不是整段攻击都检测，只在挥击瞬间。
>
> ⚠️ 本节不做过滤：`OverlapCircleAll` 不传 LayerMask，只要碰撞体圈进了范围、身上挂有 `Enemy` 组件就触发。此时的 `Damage()` 是**无参占位版**（内部只有 `Debug.Log`），真正的伤害计算要到 **095 章**引入 `CharacterStats` 后才接入。

---

### 步骤 3：Gizmos 可视化检测范围

```csharp
private void OnDrawGizmos()
{
    if (attackCheck != null)
    {
        Gizmos.DrawWireSphere(attackCheck.position, attackCheckRadius);
    }
}
```

Scene 视图中可见蓝色圆形——调整大小直到刚好覆盖攻击范围。

## 📝 核心要点

```
攻击检测流程：
  挥击动画播放
    → 到达关键帧 → Animation Event → AttackTrigger()
    → OverlapCircleAll 圈出范围内的所有碰撞体
    → 身上有 Enemy 组件就调用其无参 Damage() 占位

关键参数：
  attackCheck → 检测中心点（挂在武器前方的子物体）
  attackCheckRadius → 检测范围大小

精度控制：
  Animation Event 只在1帧触发 → 不会重复检测
  而不是在 Update 中每帧检测

伤害说明：
  本节 Damage() 无参占位（内部 Debug.Log）
  真实伤害在 095 章 CharacterStats 接入
```
