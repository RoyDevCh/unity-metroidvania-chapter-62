# 反击窗口

> **战斗** | 第 61/192 节 | [[060_战斗_反击与眩晕|⬅️ 反击与眩晕]] | [[062_战斗_玩家反击实现|➡️ 玩家反击实现]]

## 🎯 本节目标

给敌人实现一个"反击窗口"：敌人攻击的**前摇**到**后摇**这段时间里，头顶亮起红色方块提示，同时 `canBeStunned` 标记打开——此时被玩家的弹反命中，敌人就会进入眩晕状态。

## 🖥️ 操作步骤

### 步骤 1：Enemy 新增窗口字段

在 `Enemy.cs` 的眩晕信息区块中，加入"是否可被眩晕"的开关和红方块引用：

```csharp
// Enemy.cs
[Header("Stun Info")]
public float stunDuration;                       // 060 节已加
[SerializeField] protected Vector2 stunDirection; // 060 节已加
public bool canBeStunned;                        // ← 新增：反击窗口开关
[SerializeField] protected SpriteRenderer counterImage; // ← 新增：红色方块提示
```

![Enemy 新增字段](../screenshots/061_new1.jpg)

### 步骤 2：开关窗口的两个函数

由动画事件在不同时机调用，一开一关：

```csharp
// Enemy.cs
public virtual void OpenCounterAttackWindow()
{
    canBeStunned = true;
    if (counterImage != null)
        counterImage.enabled = true;
}

public virtual void CloseCounterAttackWindow()
{
    canBeStunned = false;
    if (counterImage != null)
        counterImage.enabled = false;
}
```

**解释：** 隐藏用 `counterImage.enabled = false` 而不是 `SetActive(false)`——只关掉渲染组件、物体保持激活，省去反复激活销毁的开销。声明为 `virtual` 方便以后特定敌人子类重写自己的窗口行为。

### 步骤 3：配置红色方块 Counter Image

1. 在骷髅**模型子物体（挂 Animator 的那个）**下右键 $\rightarrow$ **2D Object ▸ Sprites ▸ Square**，命名 `CounterImage`；
2. Sprite Renderer 颜色设为**红色**，Alpha ≈ **175**（半透明，不遮挡敌人）；
3. Sorting Layer 保持 Default，**Order in Layer = -10**——画在敌人身体后面；
4. 它只是个普通世界内精灵，**不需要 Canvas**；
5. 默认隐藏：把 Sprite Renderer 组件的勾选框去掉（即 `enabled = false`）；
6. 把该物体拖进 Enemy 组件的 `Counter Image` 槽位。

### 步骤 4：动画事件接线

Animator 挂在子物体上，调不到父类 `Enemy` 的方法，继续走 `EnemySkeletonAnimationTriggers` 中转：

```csharp
// EnemySkeletonAnimationTriggers.cs 追加
private void OpenCounterWindow()
{
    enemy.OpenCounterAttackWindow();
}

private void CloseCounterWindow()
{
    enemy.CloseCounterAttackWindow();
}
```

然后在 Unity 里给攻击动画加事件（选中 Skeleton 子物体打开 Animation 窗口，选择 attack clip）：

1. 时间轴拖到敌人**举武器的前摇瞬间** → Add Event → Function 选 `OpenCounterWindow ()`；
2. 时间轴拖到**攻击动作完成的后摇时刻** → Add Event → Function 选 `CloseCounterWindow ()`。

这样窗口正好覆盖"看起来能被打断"的那段时间。

### 步骤 5：CanBeStunned() 判定

```csharp
// Enemy.cs
protected virtual EnemyState GetStunnedState() => null;

public virtual bool CanBeStunned()
{
    if (!canBeStunned)
        return false;

    EnemyState stunnedState = GetStunnedState();
    if (stunnedState == null)
        return false;

    CloseCounterAttackWindow();
    stateMachine?.ChangeState(stunnedState);
    return true;
}
```

**关键句就是这一段**：窗口没开或具体敌人没有提供眩晕状态时返回 false；窗口开着就把敌人切进自己的 `stunnedState` 并返回 true。这个方法是给**玩家侧**调用的入口——下一节玩家按 Q 弹反命中时执行 `enemy.CanBeStunned()`，成功与否全看此刻窗口是否开启。

> 💡 `stunnedState` 是上一节在 `EnemySkeleton.Awake` 注册的状态字段。基类通过 `GetStunnedState()` 虚方法取得它，避免 `Enemy` 直接引用只存在于 `EnemySkeleton` 的成员。
>
> 🧪 临时自测：可在 `EnemySkeleton.Update` 里加一段 `if (Input.GetKeyDown(KeyCode.U)) stateMachine.ChangeState(stunnedState);` 强制进眩晕验证动画和红闪，确认后删掉。

## 💻 完整代码

### Enemy.cs (部分)

```csharp
[Header("Stun Info")]
public float stunDuration;
[SerializeField] protected Vector2 stunDirection;
public bool canBeStunned;
[SerializeField] protected SpriteRenderer counterImage;

public virtual void OpenCounterAttackWindow()
{
    canBeStunned = true;
    if (counterImage != null)
        counterImage.enabled = true;
}

public virtual void CloseCounterAttackWindow()
{
    canBeStunned = false;
    if (counterImage != null)
        counterImage.enabled = false;
}

protected virtual EnemyState GetStunnedState() => null;

public virtual bool CanBeStunned()
{
    if (!canBeStunned)
        return false;

    EnemyState stunnedState = GetStunnedState();
    if (stunnedState == null)
        return false;

    CloseCounterAttackWindow();
    stateMachine?.ChangeState(stunnedState);
    return true;
}
```

> **为什么需要 `GetStunnedState()`**：`CanBeStunned()` 写在通用 `Enemy` 基类里时，不能直接引用只在 `EnemySkeleton` 中声明的 `stunnedState`。基类提供虚方法，具体敌人返回自己的眩晕状态，既能编译，也方便以后复用反击窗口。

### EnemySkeletonAnimationTriggers.cs (部分)

```csharp
private void OpenCounterWindow() => enemy.OpenCounterAttackWindow();
private void CloseCounterWindow() => enemy.CloseCounterAttackWindow();
```

## 📝 核心要点

- **窗口本质**：一个布尔 + 一张图——`canBeStunned` 给代码判断，红方块给玩家读信号。
- **显隐方式**：用组件的 `enabled` 开关而不是 `SetActive`，物体常驻只关渲染。
- **Animation Events**: 前摇开窗 `OpenCounterWindow`、后摇关窗 `CloseCounterWindow`，精确卡在"可弹反"的时间段。
- **判定入口**：`CanBeStunned()` 只负责回答"现在能不能晕"，真正的调用方是下一节的玩家弹反。
- **成功后立即关窗**：进入眩晕时调用 `CloseCounterAttackWindow()`，避免同一帧或动画事件延迟期间重复触发眩晕。

Hello guys, in this video we're going to make a counterattack window for the enemies, so we can see when we can do the counterattack — the red square that appears whenever you can stun them during their attack.

First, in the stun info header of the enemy script we add a boolean `canBeStunned` and a reference to the red square image. We control this with two functions: `OpenCounterAttackWindow()` sets `canBeStunned` to true and enables the image, and `CloseCounterAttackWindow()` does the opposite, hiding it by disabling the component.

Since the animator is on a child object, we relay these calls through `EnemySkeletonAnimationTriggers`. In Unity we create a square sprite under the model, color it red with alpha around 175, set order in layer to -10 so it renders behind the enemy, and leave its renderer disabled by default.

In the attack animation we add an `OpenCounterWindow` event at the wind-up frame and a `CloseCounterWindow` event when the attack finishes. Finally we implement `CanBeStunned()` — if the window is closed it returns false; otherwise the enemy switches into its stunned state and it returns true. The player side will call this in the next lesson.
