## 🎯 本节目标

添加受击时的视觉反馈：新建 `EntityFX` 脚本，让角色受击瞬间切换白色材质闪白一下，再恢复原材质。

---

## 🖥️ 操作步骤

### 步骤 1：新建 EntityFX.cs 完整脚本

新建一个独立于 `Entity` 的特效脚本 `EntityFX`，专门负责受击闪白：

```csharp
// EntityFX.cs
using System.Collections;
using UnityEngine;

public class EntityFX : MonoBehaviour
{
    [SerializeField] private Material hitMaterial;   // 受击时切换的白色材质
    [SerializeField] private float flashDuration = 0.2f;

    private SpriteRenderer sr;
    private Material originalMaterial;

    void Start()
    {
        sr = GetComponentInChildren<SpriteRenderer>(); // SpriteRenderer 在子物体上
        originalMaterial = sr.material;                // 记住原材质，方便恢复
    }

    public IEnumerator FlashFX()
    {
        sr.material = hitMaterial;                      // 闪白
        yield return new WaitForSeconds(flashDuration);
        sr.material = originalMaterial;                 // 恢复
    }
}
```

### 步骤 2：制作纯白闪烁材质 hitFX

1. Project 窗口右键 → **Create ▸ Shader ▸ GUI/Text Shader**（这类 shader 默认显示纯白，不受光照影响）
2. 再**右键这个 shader 文件 → Create ▸ Material**，Unity 会自动用该 shader 生成材质 → 命名 `hitFX`
3. 给 Player 和 Enemy 都 **Add Component ▸ EntityFX**
4. 把 `hitFX` 材质分别拖进两者 EntityFX 组件的 `Hit Material` 槽位（各自独立配置）

![白色材质](../screenshots/057_b.jpg)

### 步骤 3：在 Entity 中引用 EntityFX 并触发闪白

```csharp
// Entity.cs
protected EntityFX fx;

protected virtual void Awake()
{
    rb = GetComponent<Rigidbody2D>();
    fx = GetComponentInChildren<EntityFX>(); // EntityFX 挂在角色根物体上
}

// 受击占位入口：本阶段伤害系统尚未完成，真正的伤害计算
// 在 095 章 CharacterStats 接入，这里只负责触发受击表现
public virtual void Damage()
{
    fx.StartCoroutine("FlashFX");
}
```

> 🔑 用 `fx.StartCoroutine("FlashFX")` 而不是自己的 `StartCoroutine`，是为了让协程跑在 `EntityFX` 自己身上，特效逻辑与实体逻辑解耦；字符串调用对应的是 `EntityFX` 里的 `FlashFX` 方法名。

## 📝 核心要点

```
受击闪白流程：
  被攻击 → Damage()（本阶段无参占位）
    → fx.StartCoroutine("FlashFX")
    → SpriteRenderer 材质切换为 hitMaterial
    → 等 flashDuration(0.2s) 后恢复 originalMaterial

要点：
  EntityFX 挂在每个需要受击反馈的角色上（Player / Enemy 各拖一次材质）
  GUI/Text Shader 生成的纯白材质不受光照影响，闪白最干净
  真实伤害在 095 章 CharacterStats 接入
```
