## 🎯 本节目标

把冲刺从"只能在地面上触发"升级为**全局可触发**（跳跃中、攻击中都能闪避），加入独立的方向判定 `dashDir` 与冷却计时器，并让 Y 轴速度归零实现笔直冲刺。

### 步骤 2：方向判定与冷却都写在这个函数里

```csharp
private void CheckForDashInput()
{
    // 冷却计时器持续倒计时
    dashUsageTimer -= Time.deltaTime;

    if (Input.GetKeyDown(KeyCode.LeftShift) && dashUsageTimer < 0)
    {
        // 按下瞬间重置计时器
        dashUsageTimer = dashCooldown;

        // 记录按下冲刺那一刻的水平输入
        dashDir = Input.GetAxisRaw("Horizontal");

        // 没给方向 → 朝当前面向冲刺
        if (dashDir == 0)
            dashDir = facingDir;

        stateMachine.ChangeState(dashState);
    }
}
```

![CheckForDashInput](../screenshots/036_new2.jpg)

> ⚠️ **封装注意**：`dashDir` 是 `{ get; private set; }`，只有 `Player` 自己能赋值。所以"读输入 $\rightarrow$ 定方向 $\rightarrow$ 切状态"必须像上面这样写在 Player 内部；在 `PlayerDashState` 等外部脚本里写 `player.dashDir = ...` 会直接编译报错。
>
> 💡 如果想改成"没有方向输入就干脆不冲"，把 `ChangeState` 包进 `if (dashDir != 0)` 即可；视频选择的是"无输入朝面向冲"。Inspector 里把 **Dash Cooldown 设为 1** 秒（视频内数值）。

### 步骤 3：DashState 改用 dashDir 并锁定 Y 轴

```csharp

public override void Update()

    // Y 速度恒为 0：空中冲刺也不再下坠，轨迹笔直
```

原来乘 `player.facingDir` 的地方全部换成 `player.dashDir`。

### 步骤 4：修冲刺结束后的动画衔接

冲刺途中离开地面后回到 Idle 会播放"走路"残影动画。在 `PlayerGroundedState.Update()` 中**追加一条**判断（原有的跳跃检测保留，不要整段替换）：

```csharp
// PlayerGroundedState.cs
public override void Update()
{
    base.Update();

    // 不在地面 → 立刻交给空中状态
    if (!player.isGroundDetected())
        stateMachine.ChangeState(player.airState);

    if (Input.GetKeyDown(KeyCode.Space) && player.isGroundDetected())
        stateMachine.ChangeState(player.jumpState);
}
```

## 💻 完整代码

### Player.cs（冲刺输入部分）

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    [Header("Dash Info")]
    [SerializeField] private float dashCooldown;
    private float dashUsageTimer;
    public float dashDir { get; private set; }

    // ... 已有成员不变 ...

    private void Update()
    {
        stateMachine.currentState.Update();
        CheckForDashInput();
    }

    private void CheckForDashInput()
    {
        dashUsageTimer -= Time.deltaTime;

        if (Input.GetKeyDown(KeyCode.LeftShift) && dashUsageTimer < 0)
        {
            dashUsageTimer = dashCooldown;

            dashDir = Input.GetAxisRaw("Horizontal");

            if (dashDir == 0)
                dashDir = facingDir;

            stateMachine.ChangeState(dashState);
        }
    }
}
```

## 📝 核心要点

- **全局输入**：跨状态的通用技能（冲刺）把输入检测放在 Player 主脚本，作为状态模式的例外。
- **方向解耦**：`facingDir`（视觉朝向）$\neq$ `dashDir`（本次冲刺方向）；按下瞬间采样输入，冲刺途中不再改变。
- **封装正确用法**：`{ get; private set; }` 的字段只能在声明类内部赋值——这正是把判定放进 `CheckForDashInput()` 的原因。
- **速度锁定**：冲刺时 Y 速度清零，消除重力弧线，获得干脆的线性位移。
- **状态回溯**：`PlayerGroundedState` 每帧确认真的在地上，否则立刻让位给 `PlayerAirState`，避免动画卡在错误状态。
