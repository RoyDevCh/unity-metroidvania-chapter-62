# 攻击状态完善

> **状态机** | 第 41/192 节 | [[040_状态机_连击攻击状态|⬅️ 连击攻击状态]] | [[042_状态机_攻击方向|➡️ 攻击方向]]

## 🎯 本节目标

消除攻击时的"滑步"，给每段攻击加上不同的打击位移与惯性停顿，并用 `isBusy` 协程锁死攻击衔接瞬间误触发的移动。

> ⏳ 本节类名仍为 `PlayerPrimaryAttack`（042 节才改名为 `PlayerPrimaryAttackState`），以下代码在 040 版基础上继续完善。

## 🖥️ 操作步骤

### 步骤 1：攻击时停止滑动

角色边跑边攻击会滑行。在 `Update()` 中，当状态计时器耗尽后持续把速度清零：

![Animation Event 与动画窗口](../screenshots/041_new1.jpg)

```csharp
public override void Update()
{
    base.Update();

    if (triggerCalled)
        stateMachine.ChangeState(player.idleState);

    // 计时器归零后每帧清零速度 → 无法再滑步
    if (stateTimer < 0)
        rb.velocity = new Vector2(0, 0);
}
```

### 步骤 2：保留一点惯性

完全急停太僵硬。在 `Enter()` 里给 `stateTimer` 设 **0.1 秒**——这 0.1s 内不清速度，保留一小段前冲惯性：

```csharp
// Enter() 中追加（放在 SetInteger 之后）
stateTimer = .1f;
```

先滑行 0.1 秒再定住，观感是"收招顿挫"而非"急刹车"。

### 步骤 3：调整动画节奏

Animator / Animation 窗口中：

- **playerAttack1**：Sample Rate $\rightarrow$ **15**；
- **playerAttack2**：Sample Rate $\rightarrow$ **12**；
- **playerAttack3**：Sample Rate $\rightarrow$ **12**，并把末尾的 AnimationTrigger 事件**提前一帧**，别让重击拖太久。

![采样率调整](../screenshots/041_new2.jpg)

### 步骤 4：isBusy 锁定机制

问题根源：两段攻击之间会瞬入 Idle，而 Idle 一检测到 xInput 就切 Move，于是能"走位打断连招"。用布尔锁挡住它。

#### A. Player 中定义字段与协程

```csharp
// Player.cs
public bool isBusy { get; private set; }

public IEnumerator BusyFor(float _seconds)
{
    isBusy = true;

    yield return new WaitForSeconds(_seconds);

    isBusy = false;
}
```

> 💡 协程不能像普通函数那样直接 `BusyFor(.15f)` 调用，必须 `StartCoroutine(...)`。调试时可先传 `5f` 并在前后各加一行 `Debug.Log("IsBusy"/"NotBusy")` 验证，确认后再改成 `.15f`。

#### B. 攻击状态 Exit 时启动锁定

```csharp
public override void Exit()
{
    base.Exit();

    player.StartCoroutine("BusyFor", .15f);

    comboCounter++;
    lastTimeAttacked = Time.time;
}
```

#### C. IdleState 切换移动前检查

```csharp
// PlayerIdleState.Update()
if (xInput != 0 && !player.isBusy)
    stateMachine.ChangeState(player.moveState);
```

0.15 秒的锁玩家察觉不到，但足以吞掉状态切换间隙的那一次输入。

### 步骤 5：每段攻击专属位移

三段攻击力度不同，位移也应该不同——用数组存：

```csharp
// Player.cs
[Header("Attack Details")]
public Vector2[] attackMovement;
```

```csharp
// Enter() 中，把 SetVelocity 换成按段取值（x 还要乘朝向）
player.SetVelocity(player.attackMovement[comboCounter].x * player.facingDir,
                   player.attackMovement[comboCounter].y);
```

- Inspector 里把数组长度设为 3，逐段调出手感。
- 参考配置（**视频内 Inspector 数值**，试到满意为止）：第一段 `(2, 3)`、第二段 `(1, 2)`、第三段 `(3, 2)`——第三段最重所以位移最大。

运行测试：攻击带小跳步、三段节奏分明、连招间隙无法走位。

### 步骤 6：清理与小技巧

- 顺手抽个工具函数替换所有"清零速度"的写法：

```csharp
// Player.cs
public void SetZeroVelocity() => rb.velocity = new Vector2(0, 0);
```

  替换步骤 1 的清零和 `IdleState.Enter()` 的急停；`DashState.Exit()` 保持 `SetVelocity(0, rb.velocity.y)` 不动——冲刺结束要保留竖直速度。
- 可选技巧（视频中演示后删除）：想要"按住自动连击"，把 GroundedState 里的 `GetKeyDown` 改成 `GetKey`；想做攻速加成可在 Enter 里设 `player.anim.speed = 1.2f`、Exit 恢复为 1（全局生效，慎用，正式做法等属性系统）。
- 用 `#region Collision / Flip / Velocity` 折叠 Player.cs，保持整洁。

## 💻 完整代码

### PlayerPrimaryAttack.cs（041 版）

```csharp
using UnityEngine;

public class PlayerPrimaryAttack : PlayerState
{
    private int comboCounter;

    private float lastTimeAttacked;
    private float comboWindow = 2;

    public PlayerPrimaryAttack(Player _player, PlayerStateMachine _stateMachine,
                                string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();

        if (comboCounter > 2 || Time.time >= lastTimeAttacked + comboWindow)
            comboCounter = 0;

        player.anim.SetInteger("ComboCounter", comboCounter);

        player.SetVelocity(player.attackMovement[comboCounter].x * player.facingDir,
                           player.attackMovement[comboCounter].y);

        stateTimer = .1f;
    }

    public override void Update()
    {
        base.Update();

        if (triggerCalled)
            stateMachine.ChangeState(player.idleState);

        if (stateTimer < 0)
            player.SetZeroVelocity();
    }

    public override void Exit()
    {
        base.Exit();

        player.StartCoroutine("BusyFor", .15f);

        comboCounter++;
        lastTimeAttacked = Time.time;
    }
}
```

## 📝 核心要点

- **打击感三板斧**：清速度防滑步 + `stateTimer = .1f` 留惯性 + 按段位移制造轻重差异。
- **isBusy 协程锁**：`StartCoroutine("BusyFor", .15f)` 在 Exit 时启动，屏蔽连招间隙的移动输入；协程必须经 `StartCoroutine` 启动。
- **数据驱动**：`Vector2[] attackMovement` 让数值策划（未来的你）不用碰逻辑代码就能调手感。
- **动画节奏**：Sample Rate 是最快的"攻速旋钮"，事件位置决定收招硬直长短。

Hello guys, in this video we're going to improve an attack of the player. At the moment she can slide around when attacking, which is not cool. We need to add feedback and impact, similar to games like Hollow Knight or Dead Cells.

First, let's make her stop when moving and attacking: in the primary attack script, if state timer is less than zero, velocity equals zero. Then set state timer to 0.1f on Enter for a feeling of inertia.
