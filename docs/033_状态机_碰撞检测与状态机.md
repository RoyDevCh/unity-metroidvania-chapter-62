### 步骤 2：Gizmos 可视化两条射线

```csharp
private void OnDrawGizmos()
{
    // 竖直向下：地面检测线
    Gizmos.DrawLine(groundCheck.position,
        new Vector3(groundCheck.position.x, groundCheck.position.y - groundCheckDistance));

    // 水平向前：墙壁检测线（本节还没有翻转逻辑，先画朝右的方向）
    Gizmos.DrawLine(wallCheck.position,
        new Vector3(wallCheck.position.x + wallCheckDistance, wallCheck.position.y));
}
```

### 步骤 4：编写 isGroundDetected()

- Project Settings $\rightarrow$ Tags and Layers 添加 Layer **Ground**。
- Platform 的 Layer 改为 Ground；把 Platform 拖到 Player 的 `What Is Ground` 字段上。

### 步骤 6：用射线替换临时落地判定

## 💻 完整代码

### Player.cs（碰撞相关部分）

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    // ... Components / States 区域不变 ...

    [Header("Collision Info")]
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float groundCheckDistance;
    [SerializeField] private Transform wallCheck;
    [SerializeField] private float wallCheckDistance;
    [SerializeField] private LayerMask whatIsGround;

    public bool isGroundDetected() => Physics2D.Raycast(groundCheck.position, Vector2.down,
                                                            groundCheckDistance, whatIsGround);

    private void OnDrawGizmos()
    {
        Gizmos.DrawLine(groundCheck.position,
            new Vector3(groundCheck.position.x, groundCheck.position.y - groundCheckDistance));
        Gizmos.DrawLine(wallCheck.position,
            new Vector3(wallCheck.position.x + wallCheckDistance, wallCheck.position.y));
    }
}
```

> ⏳ `isWallDetected()`（037 节追加）：`Physics2D.Raycast(wallCheck.position, Vector2.right * facingDir, wallCheckDistance, whatIsGround)`，其中 `facingDir` 是下一节（034）创建的朝向字段。

## 📝 核心要点

```
碰撞检测集中在 Player.cs：
  isGroundDetected() → 脚底向下射线，调用时实时返回 bool
  OnDrawGizmos()     → Scene 视图可视化射线长度

各状态 → player.isGroundDetected() 当 bool 用，不自己发射线

GroundCheck → 脚底向下射线 → 能否跳跃/是否落地
WallCheck   → 体侧向前射线 → 037 滑墙使用（本节先备好位置）

为什么明明能跳还要地面检测？
  不加限制的话，站在敌人头顶、道具上也能起跳；
  收紧条件 = 收紧控制权，后面所有机制都受益。
```
