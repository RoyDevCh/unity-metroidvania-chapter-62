## 🎯 本节目标
通过计算背景图片的宽度并实时监测摄像机位置，实现背景在超出视野后瞬间“回弹”的逻辑，从而营造出无缝的无限循环视差背景效果。

## 🖥️ 操作步骤

### 1. 理解无限循环原理
在实现代码前，需要理解其核心逻辑：
- 准备三块相同的背景图（中心、左侧副本、右侧副本）。
- 当玩家移动导致摄像机将背景图移出视野时，代码会在一帧之内将该背景图瞬间移动到另一侧。
- 由于背景图是完全一致的，且移动发生在极短时间内，玩家在视觉上感知不到跳变，从而产生无限循环的错觉。

![原理演示](../screenshots/047_new1.jpg)

### 2. 获取背景宽度
我们需要知道背景图片的实际物理宽度，以便计算何时需要触发位置重置。通过 `SpriteRenderer` 的 `bounds` 属性可以获取。

```csharp
private float length; // 定义背景长度变量

void Start() {
    // 获取 SpriteRenderer 组件并读取其边界尺寸的 X 轴宽度
    length = GetComponent<SpriteRenderer>().bounds.size.x;
}
```
![获取宽度](../screenshots/047_new2.jpg)

### 3. 计算移动距离与边界检测
我们需要计算背景相对于起点的实际移动距离，并判断该距离是否超过了背景长度。

```csharp
// 计算当前背景层根据视差效果实际移动的距离
float distanceMoved = cam.transform.position.x * (1 - parallaxEffect);

// 如果移动距离大于 (当前X坐标 + 长度)，则将背景向右平移一个长度
if (distanceMoved > transform.position.x + length) {
    transform.position = new Vector3(transform.position.x + length, transform.position.y, transform.position.z);
}
// 如果移动距离小于 (当前X坐标 - 长度)，则将背景向左平移一个长度
else if (distanceMoved < transform.position.x - length) {
    transform.position = new Vector3(transform.position.x - length, transform.position.y, transform.position.z);
}
```

## 💻 完整代码

以下是将无限循环逻辑集成到视差脚本中的完整实现：

```csharp
using UnityEngine;

public class ParallaxBackground : MonoBehaviour
{
    public GameObject cam;
    public float parallaxEffect;
    private float length;

    void Start()
    {
        // 获取背景图片的宽度
        length = GetComponent<SpriteRenderer>().bounds.size.x;
    }

    void Update()
    {
        // 1. 基础视差移动逻辑
        float distance = cam.transform.position.x * parallaxEffect;
        transform.position = new Vector3(startpos.x + distance, transform.position.y, transform.position.z);

        // 2. 无限循环逻辑
        // 计算实际移动偏移量
        float distanceMoved = cam.transform.position.x * (1 - parallaxEffect);

        if (distanceMoved > transform.position.x + length)
        {
            transform.position = new Vector3(transform.position.x + length, transform.position.y, transform.position.z);
        }
        else if (distanceMoved < transform.position.x - length)
        {
            transform.position = new Vector3(transform.position.x - length, transform.position.y, transform.position.z);
        }
    }

    private Vector3 startpos;
    void Awake() {
        startpos = transform.position;
    }
}
```

## 📝 核心要点
- **`SpriteRenderer.bounds.size.x`**: 用于动态获取图片的实际宽度，避免在 Inspector 中手动输入数值，增加脚本通用性。
- **瞬时位移 (Snapback)**: 循环的核心在于 `transform.position` 的瞬间改变，必须在同一帧内完成以保证无缝。
- **副本依赖**: 该方案要求场景中必须存在左右对称的背景副本，否则在位移瞬间会出现空白区域。
- **性能优化**: 这种方法比不断实例化/销毁背景对象性能更高，且内存占用极低。
