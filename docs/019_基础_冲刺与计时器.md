## 本节目标

1. 理解 Time.deltaTime 是“上一帧到当前帧经过的时间”。
2. 用 dashTime 记录本次冲刺还剩多久。
3. 在冲刺期间使用 dashSpeed，结束后恢复普通移动。
4. 用 Animator 的 isDashing Bool 切换冲刺动画。

## 课程原版

### 1. 添加计时器变量

视频中的字段只有持续时间、剩余时间和冲刺速度：

~~~csharp
[Header("Dash Info")]
[SerializeField] private float dashDuration;
[SerializeField] private float dashTime;
[SerializeField] private float dashSpeed;
~~~

dashTime 是运行时递减的计时器。它不是冷却计时器，也不是“是否正在冲刺”的独立 Bool。

![冲刺源码证据](../screenshots/019_dash_code.jpg)

### 2. 每帧递减计时器

在 Update() 中保持原有的移动、输入、碰撞和翻转流程，并加入：

~~~csharp
private void Update()
{
    Movement();
    CheckInput();
    CollisionChecks();

    dashTime -= Time.deltaTime;

    FlipController();
    AnimatorControllers();
}
~~~

dashTime -= Time.deltaTime 与 dashTime = dashTime - Time.deltaTime 等价。计时器会继续减到负数，这是本课程后面用 > 0 判断状态的方式。

### 3. 按键时启动冲刺

课程原版只在按下 Shift 时把剩余时间重置为持续时间：

~~~csharp
private void CheckInput()
{
    xInput = Input.GetAxisRaw("Horizontal");

    if (Input.GetKeyDown(KeyCode.LeftShift))
        dashTime = dashDuration;
}
~~~

### 4. 冲刺期间改变速度

在 Movement() 中，根据计时器决定使用哪一个速度。视频后半段还把 Y 速度设为 0，使空中冲刺保持直线：

~~~csharp
private void Movement()
{
    if (dashTime > 0)
    {
        rb.velocity = new Vector2(xInput * dashSpeed, 0);
    }
    else
    {
        rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);
    }
}
~~~

> 课程原版的一个刻意限制：冲刺速度仍乘以当前 xInput。只按 Shift、不同时按左右时，水平速度可能为 0；视频把“没有方向时仍能冲刺”和“冷却”留到后续章节处理。不要在本节把这个限制悄悄改成另一套原码。

### 5. 接入冲刺动画

在 Animator 中创建 Bool 参数 isDashing，从 Any State 进入冲刺动画，退出时以 isDashing = false 回到普通状态。代码只负责根据 dashTime 更新参数：

~~~csharp
private void AnimatorControllers()
{
    anim.SetBool("isDashing", dashTime > 0);

    // 这里继续保留本章之前已有的动画参数
    anim.SetBool("isMoving", Mathf.Abs(rb.velocity.x) > 0);
    anim.SetFloat("yVelocity", rb.velocity.y);
    anim.SetBool("isGrounded", isGrounded);
}
~~~

![冲刺 Inspector 证据](../screenshots/019_inspector.jpg)

视频中为了观察效果曾把持续时间调到 2 秒，再调到约 0.4 秒，并把速度从 15 调到 25。它们是调试过程中的 Inspector 数值，不应被写成唯一的代码默认值；以截图和自己的手感为准。

## 课程原版的已知问题

- 本节没有 dashCooldown 或 dashUsageTimer。按住或反复按 Shift 可以连续触发，这是视频结尾明确留下的问题。
- 没有方向输入时，xInput * dashSpeed 可能得到 0。
- dashTime 同时承担“计时器”和冲刺状态判定，适合学习 Time.deltaTime，不适合作为最终大型项目的全部冲刺架构。

这些不是本页遗漏，而是课程章节边界。下一步请阅读 [[020_基础_冲刺冷却]]，再阅读 [[035_状态机_冲刺状态]] 和 [[036_状态机_冲刺状态改进]]。

### 对应文件

`UnityProject/Assets/Scripts/Player/Player.cs`

```csharp
using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    [SerializeField] private float dashSpeed = 20f;
    [SerializeField] private float dashDuration = 0.2f;

    private float dashTimer;
    private int facingDir = 1;
    private Rigidbody2D rb;

    private void Awake() => rb = GetComponent<Rigidbody2D>();

    private void Update()
    {
        dashTimer -= Time.deltaTime;
        if (Input.GetKeyDown(KeyCode.LeftShift) && dashTimer <= 0f)
        {
            dashTimer = dashDuration;
            rb.velocity = new Vector2(facingDir * dashSpeed, 0f);
        }
    }
}
```
