# 贴墙问题与物理材质

## 🎯 本节目标

解决角色跳跃时"贴在墙上"的问题——通过 Physics Material 2D 消除墙壁摩擦力。

---

## 🖥️ 操作步骤

### 步骤 1：发现问题

角色跳到墙壁旁边时，会**慢慢滑下来**而不是正常下落。这是因为 Capsule Collider 和墙壁之间有默认摩擦力。

![贴墙问题](../screenshots/018_wall.jpg)

> 🔑 默认 Physics Material 2D 的 Friction = 0.4，导致角色"粘"在墙上。

---

### 步骤 2：创建无摩擦物理材质

1. Project 窗口 → 右键 → Create → Physics Material 2D
2. 命名 `SlipperyMat`
3. 设置参数：

| 属性 | 值 | 作用 |
|------|-----|------|
| **Friction** | 0 | 无摩擦 |
| **Bounciness** | 0 | 无弹跳 |

![物理材质](../screenshots/018_material.jpg)

---

### 步骤 3：应用材质

选中 **Player** → Inspector → **Capsule Collider 2D** → Material → 拖入 `SlipperyMat`

---

### 步骤 4：测试

点 Play → 角色跳到墙边 → 不再贴墙，正常下落 ✅

---

## 📝 核心要点

```
贴墙原因：Collider2D 默认 Friction = 0.4
解决方法：给 Player 的 Collider 挂 Physics Material 2D
          Friction = 0 → 墙壁无摩擦 → 不贴墙

Physics Material 2D 属性：
  Friction (0~1)  → 摩擦力（0=光滑, 1=粗糙）
  Bounciness (0~1) → 弹性（0=不弹, 1=完全弹）
```
