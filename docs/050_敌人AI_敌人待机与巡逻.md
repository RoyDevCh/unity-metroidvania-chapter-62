# 敌人待机与巡逻

## 🎯 本节目标
搭建第一个可击败的骷髅敌人：场景层级、Rigidbody2D 配置、动画剪辑（Idle / Move）、Animator 参数，并编写 `SkeletonIdleState` 与 `SkeletonMoveState` 两个状态脚本，实现待机与巡逻的完整逻辑。


## 🖥️ 操作步骤

### 1. 场景对象构建与层级设置
首先在场景中创建敌人的物理结构，确保中心点正确且层级清晰。

1. 在 `Project` 窗口进入 `Graphics` $\rightarrow$ `enemies` $\rightarrow$ `skeleton`，将第一个 Sprite 拖入 `Scene`。
2. 将该对象重命名为 **animator**，并调整其 `Scale` 使其大小合适。
3. 将 **animator** 的 `Layer` 设置为 `enemy`。
4. 创建一个空物体作为父级，命名为 **enemy skeleton**。
5. **对齐中心点**：将子物体 **animator** 向右移动约 `0.25`，使其视觉中心与父物体原点重合。
6. 为 **enemy skeleton** 添加 `Animator` 组件。
7. 为 **enemy skeleton** 添加 `Rigidbody2D` 组件并配置：
   - **Constraints**：勾选 `Freeze Rotation Z`，防止敌人在碰撞时来回打转。
   - **Collision Detection**：设为 `Continuous`（连续碰撞检测），避免移动时穿过墙体。
   - **Interpolate**：设为 `Interpolate`，让物理位移在画面上更平滑。

### 2. 建立脚本继承体系
为了减少重复代码，我们采用 `Entity` $\rightarrow$ `Enemy` $\rightarrow$ `EnemySkeleton` 的三层继承结构。

**第一步：修改 `Enemy` 脚本**
让 `Enemy` 继承自 `Entity`，并重写必要的方法。

```csharp
public class Enemy : Entity
{
    [Header("Movement info")]
    [SerializeField] protected float moveSpeed = 1.5f;
    [SerializeField] protected float idleTime = 2f;
    [SerializeField] protected LayerMask whatIsPlayer;
    public EnemyStateMachine stateMachine { get; private set; }

    protected override void Awake()
    {
        base.Awake();
        stateMachine = new EnemyStateMachine();

    protected override void Update()

}
```

### 3. 碰撞检测与环境感知配置
设置敌人检测地面和墙壁的探测点。

1. 在 **enemy skeleton** 下创建空物体 **ground check**，将其位置向下移动至角色前方。
2. 在 Inspector 中配置以下参数：
   - **Ground Check Distance**: `0.4`
   - **Wall Check Distance**: `0.8`
   - **What Is Ground**: 设置为 `Ground` 层。

### 4. 动画剪辑（Animation Clip）制作
创建敌人的 Idle（待机）和 Move（移动）动画。

1. **目录结构**：在 `Animations` 文件夹下创建 `Controllers` 和 `Animations/Skeleton` 子文件夹。
2. **创建 Controller**：新建 `Animator Controller` 命名为 `skeleton_easy` 并赋值给 **enemy skeleton** 的 `Animator` 组件。
3. **制作 Idle 动画**：
   - 创建 Clip `skeleton_idle`。
   - 拖入 `enemies/skeleton` 的 Idle 序列帧。
   - **优化**：删除前三个冗余帧，设置 `Sample Rate` 为 `12`，确保动作连续。
4. **制作 Move 动画**：
   - 创建 Clip `skeleton_move`。
   - 拖入 Walk 序列帧，设置 `Sample Rate` 为 `10`，营造一种“自信且缓慢”的行走感。

### 5. Animator 状态机设置
在 `Animator` 窗口中配置参数以驱动动画切换。

1. 打开 `Animator` 窗口。
2. 在 `Parameters` 栏中添加两个布尔值（Boolean）：
   - `idle`
   - `move`
3. 将 `skeleton_idle` 和 `skeleton_move` 状态拖入画布并建立转换关系。

### 6. 编写待机与巡逻状态脚本
动画就绪后，为骷髅兵编写前两个状态：待机（Idle）与巡逻（Move）。两个状态都通过 `EnemyState` 的三参数构造函数 `(Enemy _enemy, EnemyStateMachine _stateMachine, string _animBoolName)` 完成初始化。

**第一步：创建 `SkeletonIdleState` 脚本**

```csharp
public class SkeletonIdleState : EnemyState
{
    public SkeletonIdleState(Enemy _enemy, EnemyStateMachine _stateMachine, string _animBoolName)
        : base(_enemy, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();
        // 进入待机时重置计时器，休息 idleTime 秒
        stateTimer = enemy.idleTime;
    }

    public override void Update()
    {
        base.Update();

        EnemySkeleton skeleton = (EnemySkeleton)enemy;
        if (enemy.IsPlayerDetected().collider != null)
        {
            stateMachine.ChangeState(skeleton.battleState);
            return;
        }

        bool hasGround = enemy.IsGroundDetected();

        // 计时结束且脚下有地面时，切换到巡逻状态
        if (stateTimer < 0 && hasGround)
            stateMachine.ChangeState(skeleton.moveState);

        // 撞到墙或已经悬空时，原地转身
        if (enemy.IsWallDetected() || !hasGround)
            enemy.Flip();
    }
}
```

**第二步：创建 `SkeletonMoveState` 脚本**

```csharp
public class SkeletonMoveState : EnemyState
{
    public SkeletonMoveState(Enemy _enemy, EnemyStateMachine _stateMachine, string _animBoolName)
        : base(_enemy, _stateMachine, _animBoolName) { }

    public override void Update()
    {
        base.Update();

        EnemySkeleton skeleton = (EnemySkeleton)enemy;
        if (enemy.IsPlayerDetected().collider != null)
        {
            stateMachine.ChangeState(skeleton.battleState);
            return;
        }

        float xInput = enemy.facingDir; // 巡逻方向就是当前朝向
        // 以巡逻速度水平移动，垂直速度保持不变；SetVelocity 内部会调用 FlipController 自动翻转
        enemy.SetVelocity(xInput * enemy.moveSpeed, enemy.rb.velocity.y);

        // 碰到墙或前方没有地面时，记录待机时长并切回待机状态
        if (enemy.IsWallDetected() || !enemy.IsGroundDetected())
        {
            stateTimer = enemy.idleTime;
            stateMachine.ChangeState(skeleton.idleState);
        }
    }
}
```

**第三步：在 `EnemySkeleton` 中实例化状态**

```csharp
public SkeletonIdleState idleState { get; private set; }
public SkeletonMoveState moveState { get; private set; }
public SkeletonBattleState battleState { get; private set; }

protected override void Awake()
{
    base.Awake();

    // 在 Awake 中实例化各个状态，动画布尔名与 Animator 参数一一对应
    idleState = new SkeletonIdleState(this, stateMachine, "idle");
    moveState = new SkeletonMoveState(this, stateMachine, "move");
    // 051 节会补充 battleState 的实现；先保留同一初始化位置。
    battleState = new SkeletonBattleState(this, stateMachine, "move");
}
```

**第四步：调用 `Initialize` 启动状态机**

```csharp
public void Initialize(EnemyState startState) => stateMachine.Initialize(startState);

protected override void Start()
{
    base.Start();          // 先让 Entity 完成 rb、anim 的获取
    Initialize(idleState); // 敌人从待机状态开始运行
}
```

**Enemy.cs（通用基类）**
```csharp
using UnityEngine;

public class Enemy : Entity
{
    [Header("Movement info")]
    [SerializeField] protected float moveSpeed = 1.5f;
    [SerializeField] protected float idleTime = 2f;
    [SerializeField] protected LayerMask whatIsPlayer;
    public EnemyStateMachine stateMachine { get; private set; }

    protected override void Awake()
    {
        base.Awake();
        stateMachine = new EnemyStateMachine();
    }

    protected override void Start()
    {
        base.Start();
    }

    protected override void Update()
    {
        stateMachine?.currentState?.Update();
    }

    public virtual RaycastHit2D IsPlayerDetected()
    {
        if (wallCheck == null)
            return default;

        return Physics2D.Raycast(wallCheck.position,
            Vector2.right * facingDir, 50f, whatIsPlayer);
    }
}
```

## 📝 核心要点
- **继承链设计**：`Entity` (通用实体) $\rightarrow$ `Enemy` (通用敌人属性) $\rightarrow$ `EnemySkeleton` (具体敌人实现)，极大提高代码复用率。
- **中心点修正**：通过偏移子物体 `animator` 的位置，使父物体作为逻辑中心，方便旋转和位移。
- **动画优化**：通过调整 `Sample Rate` 和剔除冗余帧，使像素动画更加自然流畅。
- **层级管理**：将敌人设置为 `enemy` Layer，为后续的碰撞过滤和 AI 检测打基础。
- **巡逻循环**：Idle 中计时结束切 Move；Move 中撞墙或临崖则记录 `idleTime` 切回 Idle，形成稳定的 待机 $\rightleftarrows$ 巡逻 循环。
