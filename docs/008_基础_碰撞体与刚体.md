## 🎯 本节目标

理解 Unity 2D 物理的核心：**Rigidbody2D**（刚体）和 **Collider2D**（碰撞体），让物体能受重力下落并与平台碰撞。

> ⚠️ 本节纯操作，**不需要写代码**。

---

## 🖥️ 操作步骤

### 步骤 1：创建平台和玩家

在 Hierarchy 中创建两个对象：

1. **平台**：右键 → 2D Object → Sprites → Square
   - 改名 `Platform`，在 Scene 视图中拉长做成平台形状
   - Inspector → Sprite Renderer → Color 改为深色

2. **玩家**：右键 → 2D Object → Sprites → Circle
   - 改名 `Player`，颜色改为黄色方便识别

![初始场景](../screenshots/008_setup.jpg)

> 此时点 Play，什么都没有发生。因为只有外观，没有物理。

---

### 步骤 2：添加 Rigidbody2D（刚体）

选中 Player → Inspector 底部 **Add Component** → 搜索 `Rigidbody 2D` → 添加。

![添加Rigidbody2D](../screenshots/008_rb.jpg)

现在点 Play：**球体往下掉了**——但它穿过了平台。

> 🔑 **Rigidbody2D = 受到物理引擎控制**（重力、速度、力）。只有外观（Sprite）不行。

---

### 步骤 3：添加 Collider2D（碰撞体）

1. 选中 **Player** → Add Component → `Circle Collider 2D`
2. 选中 **Platform** → Add Component → `Box Collider 2D`

![添加Collider](../screenshots/008_collider.jpg)

现在点 Play：球体掉下来**停在平台上了**！

> 🔑 **Collider 定义物体的物理形状**（用于碰撞检测）。外观 ≠ 物理形状——你可以把 collider 调得比 sprite 大或小。

---

### 步骤 4：实验物理属性

在 Player 的 Rigidbody2D 组件中试试这些参数：

| 参数 | 作用 | 试试 |
|------|------|------|
| **Gravity Scale** | 重力倍数 | 0=无重力，5=快速下落 |
| **Linear Drag** | 空气阻力 | 0.5 让弹跳更自然 |
| **Mass** | 质量 | 影响碰撞反应 |

还可以创建 **Physics Material 2D**（右键 Project → Create → Physics Material 2D），设置 **Bounciness** 让球弹跳起来：

![弹跳效果](../screenshots/008_result.jpg)

## 📝 核心要点

```
外观 (Sprite Renderer)  ≠  物理形状 (Collider2D)

要产生碰撞：
  双方都必须有 Collider2D
  至少一方有 Rigidbody2D（受物理驱动）

Rigidbody2D → 受重力、外力影响
Collider2D  → 定义碰撞边界
```
