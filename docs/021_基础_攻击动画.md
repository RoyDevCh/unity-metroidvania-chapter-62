## 🎯 本节目标

为角色添加攻击动画：鼠标左键触发攻击，通过 Animator 参数 `isAttacking`(Bool) 控制攻击状态切换，并用 **Animation Event** 在攻击帧播完后自动结束。

> 🧩 本节沿用 [[014_基础_代码重构与整理]] 重构后的 `Player.cs` 结构：`Awake` 中缓存 `rb`/`anim`，`Update` 依次调用 `Movement()` → `CheckInput()` → `AnimatorControllers()`；已有动画参数 `isMoving`/`yVelocity`/`isGrounded`。

---

## 🖥️ 操作步骤

### 步骤 1：创建攻击动画片段

1. 选中 Player → Animation 窗口 → Create New Clip
2. 命名 `playerAttack1` → 拖入攻击帧

![Animator状态机](../screenshots/021_animator.jpg)

---

### 步骤 2：设置 Animator 参数与过渡

Parameters 添加 `isAttacking` (Bool)

状态机过渡：
- `Any State` → `playerAttack1`：Condition `isAttacking == true`
- `playerAttack1` → `playerIdle`：Has Exit Time ✅（攻击帧播完自动回）

> 💡 攻击动画不要取消 Has Exit Time——需要等攻击帧播完才能回到 Idle。

---

### 步骤 3：在 clip 末帧添加 Animation Event

攻击的结束时机由 **Animation Event** 通知脚本，添加步骤：

1. 在 Animation 窗口选中 `playerAttack1`，把时间线拖到**最后一帧**
2. 右键时间线 → **Add Animation Event**
3. 在 Inspector 的 Function 下拉框中选择 `AttackOver`

> 🔑 `AttackOver` 必须是 Player 脚本里的 **public** 方法（下一步实现），否则下拉框里选不到。

---

### 步骤 4：鼠标左键触发攻击

在 `CheckInput()` 中新增鼠标左键输入（`Input.GetMouseButtonDown(0)`），并抽出 `Attack()` 方法设置参数：

```csharp
private void CheckInput()
{
    xInput = Input.GetAxisRaw("Horizontal");

    if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);

    if (Input.GetKeyDown(KeyCode.LeftShift) && dashCooldownTimer <= 0)
        StartDash();

    // 攻击输入：鼠标左键
    if (Input.GetMouseButtonDown(0))
        Attack();
}

private void Attack()
{
    isAttacking = true;
    anim.SetBool("isAttacking", true);
}
```

![攻击代码](../screenshots/021_attack_code.jpg)

---

### 步骤 5：Animation Event 回调 AttackOver

当攻击动画播到最后一帧时，Animation Event 自动调用 `AttackOver()` 结束攻击：

```csharp
// 必须是 public，Animation Event 才能在 Function 列表中选到它
public void AttackOver()
{
    isAttacking = false;
    anim.SetBool("isAttacking", false);
}
```

---

### 步骤 6：并入 Update 固定结构

保持三方法调用顺序不变，只在前面插入攻击期间的拦截逻辑：

```csharp
void Update()
{
    if (dashCooldownTimer > 0)
        dashCooldownTimer -= Time.deltaTime;

    if (isDashing)
    {
        HandleDashing();
        return;
    }

    // 攻击期间站定不动，等 Animation Event 调用 AttackOver() 结束
    if (isAttacking)
    {
        rb.velocity = new Vector2(0, rb.velocity.y);
        return;
    }

    Movement();
    CheckInput();
    AnimatorControllers();
}
```

> ⚠️ 攻击期间提前 `return`：禁止移动/跳跃输入干扰。结束时机完全交给 Animation Event，`Movement()` / `AnimatorControllers()` 不需要任何修改。

## 📝 核心要点

```
攻击流程：
  鼠标左键 GetMouseButtonDown(0) → Attack() → isAttacking = true → Animator 切到攻击动画
  攻击帧播完 → Animation Event → AttackOver() → isAttacking = false → 回到 Idle

关键：
  - AttackOver() 必须 public，否则 Animation Event 的 Function 列表里选不到
  - 攻击期间提前 return，禁止移动/跳跃输入干扰
  - 结束时机完全由 Animation Event 决定（下一节连击在此结构上扩展）
```
