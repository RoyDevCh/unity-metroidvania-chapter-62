## 🎯 本节目标

理解 C# 继承——把 Player 和 Enemy 的通用逻辑提取到基类 `Entity`，避免重复代码。

---

## 🖥️ 操作步骤

### 步骤 1：什么是继承

```
Entity (基类：所有角色的通用逻辑)
  ├── Player (子类：添加玩家特有逻辑)
  └── Enemy  (子类：添加敌人特有逻辑)
```

> 🔑 继承 = 子类自动拥有父类的所有 public/protected 变量和方法，还可以添加自己的。

---

### 步骤 2：创建 Entity 基类

把 Player 和 Enemy 共有的逻辑提取到 `Entity`：

```csharp
public class Entity : MonoBehaviour
{
    public Rigidbody2D rb { get; private set; }
    public Animator anim { get; private set; }

    public int facingDir { get; private set; } = 1;
    public bool isGrounded { get; private set; }
    public bool isWallDetected { get; private set; }

    [Header("Collision")]
    [SerializeField] protected Transform groundCheck;
    [SerializeField] protected Transform wallCheck;
    [SerializeField] protected float groundCheckDistance;
    [SerializeField] protected float wallCheckDistance;
    [SerializeField] protected LayerMask whatIsGround;

    protected virtual void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        anim = GetComponent<Animator>();
    }

    public void SetVelocity(float _xVelocity, float _yVelocity)
    {
        rb.velocity = new Vector2(_xVelocity, _yVelocity);
    }

    public void Flip()
    {
        facingDir *= -1;
        transform.Rotate(0, 180, 0);
    }

    protected virtual void CollisionChecks()
    {
        isGrounded = Physics2D.Raycast(groundCheck.position, Vector2.down,
                                        groundCheckDistance, whatIsGround);
        isWallDetected = Physics2D.Raycast(wallCheck.position,
                        Vector2.right * facingDir, wallCheckDistance, whatIsGround);
    }
}
```

### 步骤 3：Player 继承 Entity

```csharp
public class Player : Entity
{
    // Player 特有的变量
    [Header("Move Info")]
    [SerializeField] private float moveSpeed = 8f;
    [SerializeField] private float jumpForce = 12f;

    // 不需要再声明 rb, anim, facingDir —— 已从 Entity 继承！

    protected override void Awake()
    {
        base.Awake();   // 调用父类的 Awake，完成 rb / anim 的获取
    }
}
```

---

### 步骤 4：Enemy 也继承 Entity

```csharp
public class Enemy : Entity
{
    // Enemy 特有的变量
    [SerializeField] private float moveSpeed = 3f;

    // rb、anim、SetVelocity()、Flip()、CollisionChecks()
    // 全部从 Entity 继承，无需重写
}
```

## 📝 核心要点

```
继承规则：
  子类 : 父类 → 自动拥有父类 public/protected 成员
  virtual/override → 子类可以重写父类方法
  base.Method() → 调用父类的原始方法
  protected → 子类可以访问，外部不行

架构：
  Entity (通用：移动、翻转、碰撞检测)
    ├── Player (添加：输入、冲刺、连击……)
    └── Enemy  (添加：AI、巡逻、追击……)
```
