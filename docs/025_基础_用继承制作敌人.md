## 🎯 本节目标

创建敌人，复用 Entity 基类，实现简单巡逻 AI：建立 `Enemy : Entity` 基类与 `EnemySkeleton : Enemy` 子类，让骷髅沿平台匀速巡逻，走到悬崖边或撞墙时自动 `Flip` 掉头——全程只用继承，不引入任何状态机。

---

## 🖥️ 操作步骤

### 步骤 1：在 Unity 中搭建敌人物体

1. 把素材包中的骷髅精灵复制到项目的 `Graphics` 文件夹，再把精灵拖入场景。
2. 将精灵子物体重命名为 `Animator`（本节暂不配置动画，之后随时可以补上），并稍微右移，让物体原点大致位于精灵中心。
3. 选中精灵右键 → **Create Empty Parent**，命名为 `Enemy_Skeleton`。
4. 为它添加 `Rigidbody2D` 和 `Capsule Collider 2D`；碰撞体可以调得比贴图稍大——敌人应该更容易被打中。

![搭建敌人物体](../screenshots/025_1.jpg)

---

### 步骤 2：创建 Enemy 基类

新建 `Enemy` 脚本，把 `MonoBehaviour` 换成 `Entity`，并在 `Awake` 中调用 `base.Awake()` 完成 `rb` / `anim` 的初始化：

- `moveSpeed` 不上移到 `Entity`：否则 Inspector 里 Move Speed 会和 Collision Info 挤在一起，每个类用自己的 `[Header]` 分类更整洁。
- `moveSpeed` 用 `protected` 修饰：子类 `EnemySkeleton` 之后也要用到它。
- `Update` 里先执行 `CollisionChecks()`（Entity 的地面 / 墙检测），再做巡逻移动。

```csharp
using UnityEngine;

public class Enemy : Entity
{
    [Header("Move Info")]
    [SerializeField] protected float moveSpeed;

    protected override void Awake()
    {
        base.Awake(); // 调用 Entity 的 Awake，获取 rb / anim
    }

    protected virtual void Update()
    {
        CollisionChecks();

        Movement();
    }

    protected virtual void Movement()
    {
        // 沿朝向匀速移动，竖直速度保持不变（下落交给重力）
        rb.velocity = new Vector2(facingDir * moveSpeed, rb.velocity.y);
    }
}
```

### 步骤 3：EnemySkeleton 继承 Enemy

新建 `EnemySkeleton` 脚本并挂到 `Enemy_Skeleton` 物体上（`Enemy` 是基类，不单独挂物体），把 `MonoBehaviour` 改成 `Enemy`，删掉模板自带的 `Start` / `Update`：

![创建EnemySkeleton脚本](../screenshots/025_a.jpg)

```csharp
using UnityEngine;

public class EnemySkeleton : Enemy
{
    protected override void Awake()
    {
        base.Awake(); // 沿继承链依次调用 Enemy → Entity 的初始化
    }
}
```

只写了几行代码，这具骷髅就已经拥有 `rb`、`anim`、地面 / 墙检测、`Flip` 和巡逻移动——这就是继承的意义：**不必把同样的代码写两遍**。

---

### 步骤 4：巡逻掉头（悬崖 + 撞墙）

**悬崖掉头**：把 `GroundCheck` 子物体从脚底移到**角色前方**，这样 `isGrounded` 检测的就是"前方还有没有地面"。在 `Enemy.Update` 中补充判断：

```csharp
protected virtual void Update()
{
    CollisionChecks();

    // 前方没有地面（悬崖），掉头
    if (!isGrounded)
    {
        Flip();
    }

    Movement();
}
```

**撞墙掉头**：墙检测所需的 `wallCheck`、`wallCheckDistance`、`isWallDetected` 在上一节的 `Entity` 中已经备好，只需把条件补全：

```csharp
// 前方没有地面或撞到墙，都掉头
if (!isGrounded || isWallDetected)
{
    Flip();
}
```

**防呆小技巧**：哪个实体忘了给 `WallCheck` 赋值，就会报错甚至行为异常。可以在 `Entity` 的 `Awake` 里补一行兜底——没赋值就默认用自身位置：

```csharp
if (wallCheck == null)
{
    wallCheck = transform;
}
```

![未赋值WallCheck的报错](../screenshots/025_3.jpg)

### 步骤 5：物理参数配置与验证

1. **防摔倒（字幕里的小挑战）**：运行会发现骷髅走一走就倒了——在 `Rigidbody2D` 中勾选 **Freeze Rotation Z**。
2. 顺手优化：`Collision Detection` 设为 `Continuous`，`Interpolate` 设为 `Interpolate`，`Gravity Scale` 调到 `4` 左右（摔下悬崖时坠得更快，显得更"重"）。
3. **Inspector 配置**：`Move Speed` 先设慢一点（如 `1`）；`Collision Info` 中拖入 `Ground Check`（角色前方脚下）和 `Wall Check` 子物体，`Ground Check Distance` 约 `0.1`（按关卡结构可加长）、`Wall Check Distance` 约 `0.7`、`What Is Ground` 选 `Ground` 层。
4. **运行验证**：骷髅向一侧匀速走，到悬崖边或撞墙时自动 `Flip` 掉头，来回巡逻。

## 💻 完整代码

### Enemy.cs（基类）

```csharp
using UnityEngine;

public class Enemy : Entity
{
    [Header("Move Info")]
    [SerializeField] protected float moveSpeed;

    protected override void Awake()
    {
        base.Awake();
    }

    protected virtual void Update()
    {
        CollisionChecks();

        // 前方没有地面（悬崖）或撞到墙时，掉头
        if (!isGrounded || isWallDetected)
        {
            Flip();
        }

        Movement();
    }

    protected virtual void Movement()
    {
        rb.velocity = new Vector2(facingDir * moveSpeed, rb.velocity.y);
    }
}
```

### EnemySkeleton.cs（子类）

```csharp
using UnityEngine;

public class EnemySkeleton : Enemy
{
    protected override void Awake()
    {
        base.Awake();
    }
}
```

## 📝 核心要点

- **继承复用**：`EnemySkeleton` 只写了几行代码，就获得了 `Entity` 的组件引用、碰撞检测和 `Enemy` 的巡逻逻辑——不用把工作做两遍。
- **base.Awake()**：子类重写 `Awake` 时要调用 `base.Awake()`，否则 `rb` / `anim` 不会被初始化。
- **巡逻逻辑**：`!isGrounded`（前方是悬崖）或 `isWallDetected`（撞墙）时 `Flip`；移动只改水平速度 `rb.velocity = new Vector2(facingDir * moveSpeed, rb.velocity.y)`，竖直方向交给重力。
- **命名习惯**：检测类布尔值统一加 `is` 前缀（`isGrounded`、`isWallDetected`），以后输入 `is` 就能把它们一起搜出来。
- **Inspector 整洁**：`moveSpeed` 留在 `Enemy` 并配 `[Header("Move Info")]`，避免和 `Entity` 的 `Collision Info` 混在一起。

> 📌 **说明**：本节是 Crash Course 的极简演示，敌人没有任何 AI 架构。真正的敌人状态机架构将在第 48 节起引入（第 28 节会先学习状态机本身）。
