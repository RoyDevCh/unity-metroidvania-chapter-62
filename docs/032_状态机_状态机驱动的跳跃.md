## 🎯 本节目标

用继承创建"超级状态（Super State）"`PlayerGroundedState` 统一管理 Idle/Move，并实现跳跃（Jump）与下落（Fall）：一个 Blend Tree 播放两段动画，`yVelocity` 参数驱动混合。

## 🖥️ 操作步骤

### 步骤 1：创建超级状态 PlayerGroundedState

- 新建脚本 `PlayerGroundedState`，继承 `PlayerState`，生成**三参构造**并重写 `Enter` 等方法。
- 它不声明在 Player 里，只作为中间层存在。

![创建动画与状态](../screenshots/032_new1.jpg)

### 步骤 2：改造子状态继承链

- `PlayerIdleState`：`public class PlayerIdleState : PlayerState` 改为 `: PlayerGroundedState`（构造函数同样改成三参链式调用）。
- `PlayerMoveState`：同上改为继承 `PlayerGroundedState`。

改完运行一次，确认 Idle/Move 一切如常——只是"谁当爸爸"变了。

### 步骤 3：制作跳跃与下落动画

- **PlayerJump**：Animation 窗口新建 clip（存到 Animations 文件夹），拖入 Warrior Sheet 第 41–43 帧，Sample Rate = 10。
- **PlayerFall**：新建 clip，拖入下落帧（第一帧不合适就删掉，保留 3 帧），Sample Rate = 10。

![跳跃与下落动画](../screenshots/032_new2.jpg)

### 步骤 4：配置 Blend Tree

- Animator 参数面板添加 **Float** 参数 `yVelocity`。
- 把之前直接拖进来的 Jump/Fall 状态删掉，右键 $\rightarrow$ **Create State $\rightarrow$ From New Blend Tree**，命名为 `JumpFall`。
- 选中 JumpFall $\rightarrow$ Inspector 里把 Motion 指定为自身后双击进入：添加两个 Motion——**PlayerFall**（阈值 **-1**）和 **PlayerJump**（阈值 **+1**），取消勾选 **Automate Thresholds** 手动设置。
- 添加 **Bool** 参数 `Jump`：
  - 从 `idleState` 连过渡到 `JumpFall`：条件 `Jump = true`；
  - 从 `moveState` 连过渡到 `JumpFall`：条件 `Jump = true`；
  - 从 `JumpFall` 连过渡到 `Exit`：条件 `Jump = false`；
  - 这些过渡一律 **Has Exit Time ❌ / Transition Duration 0**（与 030 的设置习惯一致）。

> 📌 **与 030 方案的关系**：030 搭的"每个状态一个 Bool、代码状态机 Enter/Exit 自动开关"骨架**不变**。本节只是把跳跃/下落两段动画合并成一个 Blend Tree 子状态，进出仍由同一个 Bool `Jump` 控制——代码里 `animBoolName` 依旧只传 `"Jump"` 一个字符串。

**当前 Animator 参数总表（后续章节会持续扩充）：**

| 参数 | 类型 | 引入章节 | 用途 |
|------|------|---------|------|
| `Idle` | Bool | 030 | 待机动画开关 |
| `Move` | Bool | 030 | 移动动画开关 |
| `yVelocity` | Float | 032 | Blend Tree 混合跳跃/下落 |
| `Jump` | Bool | 032 | 跳跃/空中动画开关 |

### 步骤 7：实现跳跃与空中逻辑

```csharp
// PlayerJumpState.cs
public class PlayerJumpState : PlayerState
{
    public PlayerJumpState(Player _player, PlayerStateMachine _stateMachine,
                            string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();

        rb.velocity = new Vector2(rb.velocity.x, player.jumpForce);
    }

    public override void Update()
    {
        base.Update();

        // 开始下落 → 交给空中状态
        if (rb.velocity.y < 0)
            stateMachine.ChangeState(player.airState);
    }
}
```

```csharp
// PlayerAirState.cs
public class PlayerAirState : PlayerState
{
    public PlayerAirState(Player _player, PlayerStateMachine _stateMachine,
                            string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Update()
    {
        base.Update();

        // 临时落地判定：y 速度归零视为落地（033 节会换成真正的地面射线检测）
        if (rb.velocity.y == 0)
            stateMachine.ChangeState(player.idleState);
    }
}
```

```csharp
// PlayerGroundedState.cs —— 跳跃入口写在超级状态里，Idle/Move 自动共享
public class PlayerGroundedState : PlayerState

    public PlayerGroundedState(Player _player, PlayerStateMachine _stateMachine,
                                string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Update()
    {
        base.Update();

        if (Input.GetKeyDown(KeyCode.Space))
            stateMachine.ChangeState(player.jumpState);
    }
}
```

## 📝 核心要点

- **Super State（超级状态）**：`PlayerState` $\rightarrow$ `PlayerGroundedState` $\rightarrow$ `PlayerIdleState / PlayerMoveState`。跳跃入口只写一次，两个地面状态自动共享。
- **Blend Tree**：`yVelocity` 从 -1（下落）到 +1（上升）连续混合，一个状态节点搞定两段动画。
- **一个 Bool 管一对状态**：`jumpState` 和 `airState` 共用 `"Jump"` 参数——它们本质上是同一组空中动画的两个阶段。
- **临时落地判定**：`rb.velocity.y == 0` 只是权宜之计，033 节换成射线检测 `isGroundDetected`。
