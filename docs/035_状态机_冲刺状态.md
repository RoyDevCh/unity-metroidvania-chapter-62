### 步骤 2：实现 Enter —— 启动冲刺

```csharp
public override void Enter()
{
    base.Enter();

    stateTimer = player.dashDuration;     // 冲刺持续时间
    player.rb.gravityScale = 0;           // 关闭重力
    player.SetVelocity(player.dashSpeed * player.facingDir, 0);
}
```

---

### 步骤 3：实现 Update —— 冲刺计时

```csharp
public override void Update()
{
    base.Update();

    // 保持冲刺速度
    player.SetVelocity(player.dashSpeed * player.facingDir, 0);

    stateTimer -= Time.deltaTime;

    if (stateTimer <= 0)
    {
        // 冲刺结束 → 根据是否在地面决定下一个状态
        if (player.isGrounded)
            stateMachine.ChangeState(player.idleState);
        else
            stateMachine.ChangeState(player.airState);
    }
}
```

### 步骤 4：实现 Exit —— 恢复状态

```csharp
public override void Exit()
{
    base.Exit();

    player.rb.gravityScale = 1;                  // 恢复重力
    player.SetVelocity(0, player.rb.velocity.y); // 停止冲刺水平速度
    player.dashCooldownTimer = player.dashCooldown; // 启动冷却
}
```

## 📝 核心要点

```
FSM 冲刺流程：
  按Shift → ChangeState(dashState)
    → Enter: 关重力 + 设冲刺速度 + 设计时器
    → Update: 每帧保持速度 + 倒计时
    → 计时到 → ChangeState(idle/air)
    → Exit: 开重力 + 启动冷却

对比旧写法：
  旧：Player.cs 中 if(isDashing) { ... }
  新：PlayerDashState.cs 独立类，干净清晰
```
