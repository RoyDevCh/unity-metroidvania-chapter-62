## 🎯 本节目标
实现敌人通过 `Raycast2D` 检测玩家的功能，并引入 C# 继承（Inheritance）概念，优化从多种状态（如 Idle, Move）切换到战斗状态（Battle State）的代码结构。

## 🖥️ 操作步骤

### 1. 配置物理层级 (Layer)
为了让射线检测能够精准识别玩家，我们需要设置 Unity Layer。
- 打开 Unity 编辑器，点击右上角的 **Layers** $\rightarrow$ **Add Layer...**
- 创建 `Player` 层（Layer 6）和 `Enemy` 层（Layer 7）。
- 将玩家对象（Player GameObject）的 Layer 设置为 `Player`。
- **创建 `Enemy` 层后连子物体一起设层**：选中敌人对象（enemy skeleton）将其 Layer 设为 `Enemy`，弹出提示时选择 **Yes, change children**，确保子物体（animator 等）一并改为 `Enemy` 层。

![配置Layer](../screenshots/051_new1.jpg)

### 2. 在 Enemy 脚本中实现检测逻辑
在敌人脚本中，我们需要定义一个 `LayerMask` 并编写一个射线检测函数。这里不返回 `bool` 而是返回 `RaycastHit2D`，以便获取碰撞体的详细信息。

```csharp
// Enemy 基类（049）已经声明 whatIsPlayer；这里只需确认 Inspector 已赋值。

public virtual RaycastHit2D IsPlayerDetected()
{
    // 从墙壁检测点出发，向面对的方向发射射线
    // 距离设为 50，确保足够的检测范围
    return Physics2D.Raycast(wallCheck.position, Vector2.right * facingDir, 50f, whatIsPlayer);
}
```
**解释：** 使用第 49 节迁移到基类的 `wallCheck` 作为起点，结合 `facingDir` 确保射线始终向敌人前方发射。
**Inspector 赋值：** 回到 Unity 选中 **enemy skeleton** 对象，将 `What Is Player` 字段（LayerMask）通过下拉选择或拖拽赋值为 `Player` 层，否则射线永远检测不到玩家。

### 4. 创建战斗状态 (SkeletonBattleState)
创建 `SkeletonBattleState` 脚本，使其继承自 `EnemyState`，并使用基类的三参数构造函数（敌人、状态机、动画布尔名）。通过继承，我们可以复用基础敌人的状态逻辑。

```csharp
public class SkeletonBattleState : EnemyState
{
    private readonly EnemySkeleton skeleton;

    public SkeletonBattleState(Enemy _enemy, EnemyStateMachine _stateMachine, string _animBoolName)
        : base(_enemy, _stateMachine, _animBoolName)
    {
        skeleton = (EnemySkeleton)_enemy;
    }

    public override void Enter()
    {
        base.Enter();
        stateTimer = 5f;
    }

    public override void Update()
    {
        base.Update();

        if (enemy.IsPlayerDetected().collider != null)
        {
            stateTimer = 5f;
            return;
        }

        if (stateTimer <= 0f)
            stateMachine.ChangeState(skeleton.idleState);
    }

    public override void Exit()
    {
        base.Exit();
    }
}
```

### 5. 在敌人主体类中实例化状态
在 `EnemySkeleton` 类中声明并初始化 `BattleState`。

```csharp
public SkeletonBattleState battleState { get; private set; }

protected override void Awake()
{
    base.Awake();
    // 战斗时仍需向玩家移动，因此第三个参数复用 "move" 动画布尔值
    battleState = new SkeletonBattleState(this, stateMachine, "move");
}
```

### 6. 运用继承优化状态切换
**核心痛点：** 如果在 `IdleState` 和 `MoveState` 中分别写 `if (enemy.IsPlayerDetected())`，会导致代码重复。
**解决方案：** 将检测逻辑写在基类 `EnemyState` 中，或者在所有需要检测的状态基类中实现。这样，所有继承自该基类的状态都能自动获得切换到 `BattleState` 的能力，无需在每个子状态中重复粘贴代码。

public class EnemySkeleton : Enemy

## 📝 核心要点
- **Raycast2D**: 使用 `Physics2D.Raycast` 实现视线检测，通过 `LayerMask` 过滤目标。
- **Inheritance (继承)**: 当多个状态（Idle, Move, Patrol）需要执行相同的逻辑（如检测玩家 $\rightarrow$ 切换到战斗状态）时，应将该逻辑上移至基类，避免代码冗余。
- **Layer Management**: 必须为玩家和敌人分配不同的 Layer，否则射线可能会检测到敌人自身。
