## 🎯 本节目标
学习如何通过“提取方法（Extract Method）”将冗长的 `Update` 函数拆分为多个小型功能函数，提高代码的可读性和可维护性，并对 Unity 项目资源文件夹进行规范化管理。

> **课程阶段核对**：本节视频主要演示提取方法，组件缓存仍在 `Start()`，速度和跳跃数值从 Inspector 调整。下面完整代码沿用了知识库后续的 `Awake()` 与默认值，结构等价但不是视频的逐行原码；不要把默认值误认为课程要求的固定值。

## 🖥️ 操作步骤

### 步骤 1：提取动画控制逻辑
为了避免 `Update` 函数过于臃肿，我们将所有与动画相关的代码移至独立函数中。

1. 在类中创建私有函数 `private void AnimatorControllers()`。
2. 将原先在 `Update` 中控制 `Animator` 的代码块剪切并粘贴到该函数内。
3. 在 `Update` 函数中调用 `AnimatorControllers();`。

![提取动画函数](../screenshots/014_new1.jpg)

### 步骤 2：使用 IDE 快捷键提取功能函数
利用 IDE（如 Visual Studio 或 Rider）的重构功能快速拆分代码。

1. **提取跳跃逻辑**：选中处理跳跃（Jump）的代码行 $\rightarrow$ 按下 `Alt + Enter` $\rightarrow$ 选择 **Extract Method** $\rightarrow$ 命名为 `Jump()`。
2. **提取移动逻辑**：选中处理水平移动的代码行 $\rightarrow$ 按下 `Alt + Enter` $\rightarrow$ 选择 **Extract Method** $\rightarrow$ 命名为 `Movement()`。
3. **提取输入检测**：选中所有输入获取代码 $\rightarrow$ 按下 `Alt + Enter` $\rightarrow$ 选择 **Extract Method** $\rightarrow$ 命名为 `CheckInput()`。

![提取方法操作](../screenshots/014_new2.jpg)

### 步骤 3：优化变量作用域
将仅在特定函数中使用的全局变量转换为局部变量，以减少内存占用并提高安全性。

1. 找到原先在类顶端定义的 `bool isMoving`。
2. 将其删除，并在 `AnimatorControllers` 函数内部直接定义：`bool isMoving = ...`。
3. 这样 `isMoving` 变量仅在该函数内部可见，其他函数（如 `Jump`）无法访问，增强了代码的封装性。

### 步骤 4：清理项目资源结构
在 Unity Editor 中对资源进行分类，避免根目录混乱。

1. 在 `Project` 窗口创建名为 `Graphics` 的文件夹 $\rightarrow$ 将所有 Sprite 拖入其中。
2. 创建名为 `Animations` 的文件夹 $\rightarrow$ 将所有 `.anim` 文件和 `Animator Controller` 拖入其中。

## 💻 完整代码

> 推荐整合版：它保持视频的 `CheckInput / Movement / Jump / AnimatorControllers` 拆分顺序。逐视频复刻时只需把组件缓存改回 `Start()` 并在 Inspector 设置数值，其他拆分步骤不变。

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    [SerializeField] private float moveSpeed = 8f;
    [SerializeField] private float jumpForce = 7f;

    private Rigidbody2D rb;
    private Animator anim;
    private float xInput;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        anim = GetComponentInChildren<Animator>();
    }

    void Update()
    {
        Movement();
        CheckInput();
        AnimatorControllers();
    }

    private void CheckInput()
    {
        xInput = Input.GetAxisRaw("Horizontal");

        if (Input.GetKeyDown(KeyCode.Space))
        {
            Jump();
        }
    }

    private void Movement()
    {
        rb.velocity = new Vector2(xInput * moveSpeed, rb.velocity.y);
    }

    private void Jump()
    {
        rb.velocity = new Vector2(rb.velocity.x, jumpForce);
    }

    private void AnimatorControllers()
    {
        // isMoving 现在是局部变量，仅在此函数内有效
        bool isMoving = rb.velocity.x != 0;

        anim.SetBool("isMoving", isMoving);
    }
}
```

> 💡 数值与前文保持一致：`moveSpeed = 8`、`jumpForce = 7`（010 节统一后的数值）。

## 📝 核心要点
- **代码重构 (Refactoring)**：通过将大函数拆分为小函数，使代码逻辑从“怎么做 (How)”变为“做什么 (What)”，极大提高可读性。
- **局部变量 (Local Variable)**：变量定义在函数内部时，其生命周期仅限于该函数，有助于避免意外修改和内存浪费。
- **IDE 技巧**：`Alt + Enter` (Extract Method) 是快速清理代码的利器。
- **项目管理**：养成按功能（Graphics, Animations, Scripts, Prefabs）建立文件夹的习惯，防止项目规模扩大后难以维护。
