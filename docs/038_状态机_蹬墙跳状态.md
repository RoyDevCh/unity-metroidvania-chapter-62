### 步骤 3：实现 PlayerWallJumpState

```csharp
public class PlayerWallJumpState : PlayerState
{
    public PlayerWallJumpState(Player _player, PlayerStateMachine _stateMachine,
                                string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();

        // 本次蹬墙跳持续 0.4 秒（视频内硬编码数值，后续可按手感调整）
        stateTimer = .4f;

        // X 取反方向弹开，Y 直接复用普通跳跃力
        player.SetVelocity(5 * -player.facingDir, player.jumpForce);
    }

    public override void Update()
    {
        base.Update();

        if (stateTimer < 0)
            stateMachine.ChangeState(player.airState);

        // 蹬墙跳途中触地 → 直接回 Idle，消除落地延迟
        if (player.isGroundDetected())
            stateMachine.ChangeState(player.idleState);
    }
}
```

> ⚠️ `5` 与 `.4f` 都是视频里直接写死的数值（视频内数值），没有做成 Inspector 字段；想调手感改这两个数即可。
>
> 💡 **不需要手写 `Flip()`**：`SetVelocity()` 内部的 `FlipController(_xVelocity)`（034 节）检测到负的 X 速度会自动把角色转向弹开的一侧——与 034 的翻转版本保持统一。

### 步骤 4：滑墙中按空格触发 + return 保护

```csharp
// PlayerWallSlideState.Update()
public override void Update()
{
    base.Update();

    if (Input.GetKeyDown(KeyCode.Space))
    {
        stateMachine.ChangeState(player.wallJump);
        return;   // ← 关键：跳过本帧剩余逻辑
    }

    if (xInput != 0 && player.facingDir != xInput)
        stateMachine.ChangeState(player.idleState);

    if (player.isGroundDetected())
        stateMachine.ChangeState(player.idleState);

    if (yInput < 0)
        rb.velocity = new Vector2(0, rb.velocity.y);
    else
        rb.velocity = new Vector2(0, rb.velocity.y * 0.7f);
}
```

> 💡 为什么加 `return`：切换状态发生在同一帧内，后面缓降代码还会执行并把刚设置的蹬墙跳 X 速度覆盖掉——提前返回保护这一次赋值。

### 步骤 5：IdleState 急停

蹬墙跳落地后角色会滑行一小段。给 `PlayerIdleState.Enter()` 加急停（只清速度、**不改朝向**）：

```csharp
public override void Enter()
{
    base.Enter();

    rb.velocity = new Vector2(0, 0);
}
```

### 步骤 6：修三个贴墙 Bug

```csharp
// ① PlayerDashState.Update() —— 冲刺撞墙立刻转滑墙
public override void Update()
{
    base.Update();

    player.SetVelocity(player.dashSpeed * player.dashDir, 0f);

    if (!player.isGroundDetected() && player.isWallDetected())
        stateMachine.ChangeState(player.wallSlide);

    if (stateTimer < 0)
        stateMachine.ChangeState(player.idleState);

// ② Player.CheckForDashInput() 开头 —— 贴墙时不允许冲刺
private void CheckForDashInput()

    dashUsageTimer -= Time.deltaTime;
```

## 📝 核心要点

```
蹬墙跳流程：
  WallSlide → 按Space（return 保护）→ WallJump
    → Enter: SetVelocity(5 * -facingDir, jumpForce)，自动翻转
    → Update: 计时 0.4s 到点回 Air；中途着地回 Idle

关键数值（视频内硬编码）：
  弹开的水平速度 = 5 × -facingDir
  状态时长 stateTimer = 0.4s
  垂直速度复用 jumpForce

同帧覆盖问题：ChangeState 后用 return 挡住旧逻辑，
防止滑墙缓降代码抹掉刚赋予的速度。
```
