### 步骤 2：制作攻击动画

- Warrior Sheet 里一套连击共两段动作，外加一记冲刺斩；本课程要把它拆成**三段**：
  - `playerAttack1`：第一段 8 帧，Sample Rate 10；
  - `playerAttack2`：第二段（约 22–25 帧），Sample Rate 10；
  - `playerAttack3`：借用冲刺斩（77 到最后约 83 帧），Sample Rate 10。
- **本节只接 Attack1**，2、3 留给 040 连击用。想加快攻速可以调 Sample Rate 或动画 Speed。

### 步骤 3：Animator 过渡（这次要勾 Has Exit Time！）

- 添加 **Bool** 参数 `Attack`。
- 进入：`Entry/idleState` $\rightarrow$ `playerAttack1`，条件 `Attack = true`，Has Exit Time ❌、Duration 0。
- 退出：`playerAttack1` $\rightarrow$ `Exit`，条件 `Attack = false`，**这次必须勾选 Has Exit Time**（保持默认值即可）、Transition Duration 0。

> 💡 **和 030"全部取消 Has Exit Time"并不矛盾**：030 的过渡时机完全由代码状态机控制（Enter/Exit 即时开关 Bool），不需要动画系统帮忙；而攻击要求"整套动作至少完整播放一次"，勾上 Exit Time 才能保证动画不被中途截断。

### 步骤 5：triggerCalled 机制（基类改造）

```csharp
// PlayerState.cs 本节后的全貌
public class PlayerState
{
    protected PlayerStateMachine stateMachine;
    protected Player player;
    private string animBoolName;

    protected Rigidbody2D rb;
    protected float xInput;
    protected float yInput;
    protected float stateTimer;
    protected bool triggerCalled;          // ← 新增

    public PlayerState(Player _player, PlayerStateMachine _stateMachine,
                        string _animBoolName)
    {
        player = _player;
        stateMachine = _stateMachine;
        animBoolName = _animBoolName;
    }

    public virtual void Enter()
    {
        player.anim.SetBool(animBoolName, true);
        rb = player.rb;
        triggerCalled = false;             // ← 每次进入都复位
    }

    public virtual void Update()
    {
        stateTimer -= Time.deltaTime;

        xInput = Input.GetAxisRaw("Horizontal");
        yInput = Input.GetAxisRaw("Vertical");

        player.anim.SetFloat("yVelocity", rb.velocity.y);
    }

    public virtual void Exit()
    {
        player.anim.SetBool(animBoolName, false);
    }

    // ← 新增：供动画事件调用
    public virtual void AnimationFinishTrigger() => triggerCalled = true;
}
```

> 💡 为什么不用计时器？三段攻击时长各不相同，凑合能算；可如果做格斗游戏要 20 连击呢？为每段维护一个计时器不可持续。动画事件才是通用解。

### 步骤 7：Player 提供事件入口

```csharp
// Player.cs
public void AnimationTrigger() => stateMachine.currentState.AnimationFinishTrigger();
```

调用它会找到**当前状态**并触发完成标志——无论当时处于哪个状态都能正确送达。

### 步骤 8：子物体挂 PlayerAnimationTriggers 脚本

Animator 挂在子物体上，而 `AnimationTrigger()` 在父物体的 Player 里，需要一个"传话"脚本：

- 新建脚本 **PlayerAnimationTriggers**，挂到**有 Animator 组件的那个子物体**上。

```csharp
using UnityEngine;

public class PlayerAnimationTriggers : MonoBehaviour
{
    private Player player => GetComponentInParent<Player>();

    private void AnimationTrigger() => player.AnimationTrigger();
}
```

### 步骤 9：在动画里添加 Animation Event

- 选中 Player 的子物体打开 **Animation** 窗口，选择 `playerAttack1`。
- 把时间线拖到**最后一帧（或其后一格）**，点击 **Add Event**。
- 在 Inspector 的 Function 下拉里选 **AnimationTrigger ()**。

运行测试：按下鼠标左键攻击一次，动画播完自动回到 Idle。

## 💻 完整代码

### PlayerPrimaryAttack.cs（本节版本）

```csharp
using UnityEngine;

public class PlayerPrimaryAttack : PlayerState
{
    public PlayerPrimaryAttack(Player _player, PlayerStateMachine _stateMachine,
                                string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();
    }

    public override void Update()
    {
        base.Update();

        if (triggerCalled)
            stateMachine.ChangeState(player.idleState);
    }

    public override void Exit()
    {
        base.Exit();
    }
}
```

### 回调链路一览

```
Animation Event（playerAttack1 末帧）
  → PlayerAnimationTriggers.AnimationTrigger()     （子物体脚本）
    → player.AnimationTrigger()                     （Player 入口）
      → stateMachine.currentState.AnimationFinishTrigger()
        → triggerCalled = true                      （当前状态置位）
          → PlayerPrimaryAttack.Update() 检测到 → ChangeState(idleState)
            → Exit() 把 "Attack" 设回 false → 动画过渡带 Exit Time 完整收尾
```

> ⏭️ 预告：**040** 把本节的单段攻击扩展为 `comboCounter` 三段连击版（Enter/Exit 逻辑会被替换）；**042** 把类名改名为 `PlayerPrimaryAttackState`。

## 📝 核心要点

```
triggerCalled 三件套：
  基类字段        protected bool triggerCalled
  Enter 复位      triggerCalled = false
  完成触发        AnimationFinishTrigger() → true

Animation Event 接线三步：
  子物体挂 PlayerAnimationTriggers
  动画末帧 Add Event
  Function 选 AnimationTrigger()

设计动机：状态不知道动画多长，动画自己说"我演完了"。
20 连击也不用改一行计时逻辑。
```
