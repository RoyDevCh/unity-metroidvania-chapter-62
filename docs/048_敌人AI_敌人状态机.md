### 2. 创建状态机类 `EnemyStateMachine`
状态机负责管理当前处于哪个状态以及如何切换状态。
- 创建 C# 脚本 `EnemyStateMachine`。
- **注意**：该类不需要继承 `MonoBehaviour`。

```csharp
public class EnemyStateMachine
{
    public EnemyState currentState { get; private set; }

    public void Initialize(EnemyState startState)
    {
        ChangeState(startState);
    }

    public void ChangeState(EnemyState newState)
    {
        if (newState == null)
            return;

        currentState?.Exit();

        currentState = newState;
        currentState?.Enter();
    }
}
```
**解释**：`Initialize` 用于设置初始状态，`ChangeState` 负责在退出旧状态和进入新状态之间进行平滑过渡。

### 3. 创建状态基类 `EnemyState`
所有具体的敌人状态（如：巡逻、攻击、受伤）都将继承自这个基类。
- 创建 C# 脚本 `EnemyState`。
- 同样删除 `MonoBehaviour` 继承。

```csharp
using UnityEngine;

public class EnemyState
{
    protected EnemyStateMachine stateMachine;
    protected Enemy enemy;
    protected Animator anim;
    protected Rigidbody2D rb;
    protected string animBoolName;

    protected float stateTimer;
    protected bool triggerCalled;

    public EnemyState(Enemy _enemy, EnemyStateMachine _stateMachine, string _animBoolName)
    {
        this.enemy = _enemy;
        this.stateMachine = _stateMachine;
        this.animBoolName = _animBoolName;
        this.anim = _enemy.anim;
        this.rb = _enemy.rb;
    }

    public virtual void Update()
    {
        stateTimer -= Time.deltaTime;
    }

    public virtual void Enter()
    {
        triggerCalled = false;
        if (anim != null && !string.IsNullOrEmpty(animBoolName))
            anim.SetBool(animBoolName, true);
    }

    public virtual void Exit()
    {
        if (anim != null && !string.IsNullOrEmpty(animBoolName))
            anim.SetBool(animBoolName, false);
    }

    public virtual void AnimationFinishTrigger() => triggerCalled = true;
}
```
**解释**：
- `triggerCalled`：动画事件触发器标记。进入状态时先复位为 `false`，等动画事件调用 `Trigger()` 后置为 `true`，用于判断触发类动画是否播完。
- `stateTimer`：用于记录当前状态持续的时间，每帧在 `Update` 中递减。
- 构造函数参数带下划线前缀（`_enemy`、`_stateMachine`、`_animBoolName`），避免与同名成员变量混淆。
- `virtual` 关键字：允许子类重写 `Enter`、`Exit` 和 `Update` 方法。

### 4. 第 049 节整合预览：敌人主体类 `Enemy`
这是挂载在 GameObject 上的主脚本，用于持有组件引用，并驱动状态机。

```csharp
using UnityEngine;

public class Enemy : MonoBehaviour
{
    public Rigidbody2D rb { get; private set; }
    public Animator anim { get; private set; }
    public EnemyStateMachine stateMachine { get; private set; }

    protected virtual void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        anim = GetComponent<Animator>();
        stateMachine = new EnemyStateMachine();
    }

    protected virtual void Update()
    {
        stateMachine.currentState?.Update();
    }
}
```
**解释**：
- `EnemyStateMachine` 是纯 C# 类，不会自动挂到物体上，必须在 `Awake` 中手动 `new` 出来。
- `Enemy.Update` 每帧把执行权转发给当前状态：`stateMachine.currentState.Update()`，之后所有敌人逻辑都写在各个状态内部。

### 5. 第 049 节整合预览：配置敌人的 Rigidbody2D
在 Unity 编辑器中选中敌人物体（Skeleton），检查其 `Rigidbody2D` 组件：
- **Constraints**：勾选 `Freeze Rotation Z`，防止敌人在碰撞时来回打转。
- **Collision Detection**：设为 `Continuous`（连续碰撞检测），避免后续战斗中高速位移时穿过墙体。
- **Gravity Scale**：保持默认 `1`，让敌人正常受重力下落到地面。

## 📝 核心要点
- **解耦设计**：`EnemyStateMachine` 和 `EnemyState` 不继承 `MonoBehaviour`，这样它们就变成了纯 C# 类，减少了内存开销并提高了逻辑清晰度。
- **状态切换流程**：`Exit()` $\rightarrow$ `Assign New State` $\rightarrow$ `Enter()`。
- **triggerCalled 机制**：`Enter` 中先复位为 `false`，为后续动画触发器（Animation Trigger）判断做好准备。
- **物理组件**：敌人的 `Rigidbody2D` 记得勾选 `Freeze Rotation Z` 并把 `Collision Detection` 设为 `Continuous`。
- **代码复用**：敌人的状态机逻辑与玩家高度相似，通过重复构建而非直接复制，可以加深对状态模式（State Pattern）的理解。
