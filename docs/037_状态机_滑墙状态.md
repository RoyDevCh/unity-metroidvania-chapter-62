### 步骤 1：给空中补回移动能力

现在空中完全不能左右移动，没法主动贴墙。在 `PlayerAirState.Update()` 中加入：

public override void Update()
{
    base.Update();

    if (xInput != 0)
        player.SetVelocity(player.moveSpeed * 0.8f * xInput, rb.velocity.y);

    if (player.isGroundDetected())
        stateMachine.ChangeState(player.idleState);

### 步骤 2：防粘墙物理材质

测试会发现按住方向键角色会粘在墙上不掉——这是碰撞体摩擦力在捣乱。

- Project 窗口新建文件夹 `Materials` $\rightarrow$ 右键 Create $\rightarrow$ 2D $\rightarrow$ **Physics Material 2D**，命名 `Slippy`，**Friction = 0**。
- 选中 Player 的 **Capsule Collider 2D**，把 Slippy 拖到 Material 槽。

### 步骤 5：增量添加墙壁射线（只加墙，不动地面）

033 节已经备好了 `wallCheck` / `wallCheckDistance` 字段和 Gizmos，本节只需在 `Player.cs` 中**追加一个方法**：

```csharp
// Player.cs —— 加在 isGroundDetected() 下面
public bool isWallDetected() => Physics2D.Raycast(wallCheck.position,
    Vector2.right * facingDir, wallCheckDistance, whatIsGround);
```

> ⚠️ **不要**把 033 的地面检测代码再抄一遍——本节只新增上面这一个方法。`Vector2.right * facingDir` 让射线自动跟随朝向，两面墙都能测到。
>
> 💡 先 `Debug.Log(isWallDetected())` 验证：贴墙输出 true、离开输出 false（记得把 Debug 放进 `Update()`，放 `Start()` 只会打印一次）。测试时把 `Wall Check Distance` 调小些（如 0.02 附近，视频内数值），让角色更贴近墙面。

### 步骤 8：实现滑墙逻辑

```csharp
// PlayerWallSlideState.cs
public class PlayerWallSlideState : PlayerState
{
    public PlayerWallSlideState(Player _player, PlayerStateMachine _stateMachine,
                                 string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Update()
    {
        base.Update();

        // 输入的是背离墙的方向 → 离墙，回 Idle（随后自然落回 Air）
        if (xInput != 0 && player.facingDir != xInput)
            stateMachine.ChangeState(player.idleState);

        // 触地 → 回 Idle
        if (player.isGroundDetected())
            stateMachine.ChangeState(player.idleState);

        // 缓降：按住"下"则正常速度下滑
        if (yInput < 0)
            rb.velocity = new Vector2(0, rb.velocity.y);
        else
            rb.velocity = new Vector2(0, rb.velocity.y * 0.7f);
    }
}
```

> 💡 这里**直接写 `rb.velocity`** 而不是 `SetVelocity(0, ...)`：X 归零防止角色往墙里挤，Y 乘 0.7 实现缓降——视频即如此（没有 wallSlideSpeed 变量）。
>
> 🔧 可选微调：若角色滑墙时视觉上"悬空"，把滑墙几帧精灵的 Sprite Editor 里 Offset 向墙侧移一点（视频约 4.65 / 0.5，视频内数值）。

## 📝 核心要点

```
进入滑墙：AirState 中 isWallDetected() → wallSlide
滑墙行为：X 速度归零 + Y 速度 × 0.7 缓降（按住 ↓ 恢复正常下滑）
退出滑墙：着地 / 输入背离墙方向 → Idle → Air

防粘墙：Friction = 0 的 Physics Material 2D 挂在 Capsule Collider 上
射线方向：Vector2.right * facingDir，翻转后自动朝另一侧

本节只新增 isWallDetected() 一个方法，033 的地面检测保持原样。
```
