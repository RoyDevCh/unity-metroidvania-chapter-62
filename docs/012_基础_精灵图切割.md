# 精灵图切割

> **基础** | 第 12/192 节 | [[011_基础_SerializeField|⬅️ SerializeField]] | [[013_基础_Animator 动画控制器|➡️ Animator 动画控制器]]

---

## 🎯 本节目标

将一张整合的角色精灵图（Sprite Sheet）导入 Unity 并切割成单独的帧，用于后续动画制作。

---

## 🖥️ 操作步骤

### 步骤 1：导入精灵图

1. 将精灵图文件（如 `Warrior_Sheet.png`）拖入 Project 窗口的 `Assets/Sprites` 文件夹
2. 选中图片 → Inspector 中修改以下设置：

![导入设置](../screenshots/012_import.jpg)

| 设置项 | 值 |
|--------|-----|
| **Texture Type** | Sprite (2D and UI) |
| **Sprite Mode** | Multiple（重要！多帧图必须选 Multiple） |
| **Pixels Per Unit** | 根据像素风格，通常 `32` 或 `16` |
| **Filter Mode** | Point (no filter)（像素风必须选 Point，避免模糊） |

3. 点击 **Apply** 保存设置

---

### 步骤 2：切割精灵图

1. 点击 Inspector 底部的 **Sprite Editor** 按钮
2. 在 Sprite Editor 中点击 **Slice** 下拉菜单：

![切割操作](../screenshots/012_slice.jpg)

3. 切割参数：

| 参数 | 值 | 说明 |
|------|-----|------|
| **Type** | Automatic | 自动检测帧 |
| 或 **Type** | Grid By Cell Size | 手动输入每帧尺寸 |
| **Pivot** | Bottom | 锚点设为底部，脚踩地面 |
| **Padding** | 2-4px | 帧之间留间隔防止串帧 |

4. 点击 **Slice** → 点击 **Apply** 保存

---

### 步骤 3：确认切割结果

回到 Project 窗口，点击精灵图左侧的展开箭头 ▶，可以看到所有切出的单独帧：

![切割结果](../screenshots/012_result.jpg)

> 💡 检查每一帧是否完整。如果帧之间有重叠或缺失，回到 Sprite Editor 调整 **Cell Size** 或 **Padding** 重新切割。

## 📝 核心要点

```
Sprite Sheet（一张大图）
    ↓ Sprite Mode = Multiple + Sprite Editor Slice
单独的 Sprite 帧（每帧一个文件）
    ↓ 下一节 Animator
Animation Clip（动画片段）
```

> ⚠️ 像素风格游戏务必设置 **Filter Mode = Point**，否则会出现模糊！
