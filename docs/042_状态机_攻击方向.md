# 攻击方向

> **状态机** | 第 42/192 节 | [[041_状态机_攻击状态完善|⬅️ 攻击状态完善]] | [[043_关卡_Tile Palette 关卡绘制|➡️ Tile Palette 关卡绘制]]

## 🎯 本节目标

允许玩家在**每段攻击发起的瞬间**用方向键选择攻击朝向——打右边的敌人后，下一击立刻转向左边追击，而不用等角色跑过去转身。

> 🔁 **本节先把 039 创建的 `PlayerPrimaryAttack` 改名为 `PlayerPrimaryAttackState`**——从这节起全库类名统一带 `State` 后缀。此前章节文档中出现的 `PlayerPrimaryAttack` 均指同一个类。

## 🖥️ 操作步骤

### 步骤 1：重命名脚本保持命名一致

1. 在 Visual Studio 中右键类名 `PlayerPrimaryAttack` $\rightarrow$ 重命名（或按 `Ctrl + R, R`）。
2. 改为 `PlayerPrimaryAttackState`。
3. **务必勾选 Rename symbols file**，类与文件同步改名、所有引用自动更新。

![重命名脚本](../screenshots/042_new1.jpg)

### 步骤 2：在 Enter 中声明攻击方向变量

攻击位移发生在 Enter 的那次 `SetVelocity` 里，所以方向也要在这一刻确定。用 `#region` 折叠这段逻辑：

```csharp
public override void Enter()
{
    base.Enter();

    if (comboCounter > 2 || Time.time >= lastTimeAttacked + comboWindow)
        comboCounter = 0;

    player.anim.SetInteger("ComboCounter", comboCounter);

    #region Choose attack direction
    // 默认沿用当前面向
    float attackDirection = player.facingDir;

    // 发起攻击的瞬间有方向输入 → 以输入为准
    if (xInput != 0)
        attackDirection = xInput;
    #endregion

    player.SetVelocity(player.attackMovement[comboCounter].x * attackDirection,
                       player.attackMovement[comboCounter].y);

    stateTimer = .1f;
}
```

![攻击方向代码](../screenshots/042_new2.jpg)

### 步骤 3：理解"变向不变身"

- `attackDirection` 是**局部 float**，只参与这一次位移的方向计算；
- 它**不会**修改 `player.facingDir` 本身——角色的翻转依旧由 `SetVelocity()` 内部的 `FlipController()` 自动处理；
- ⚠️ 不要写 `player.facingDir = attackDirection`：该属性是 `{ get; private set; }`，在状态脚本里赋值会直接编译报错。
- 两段攻击之间按住反方向再点击，第二段就会反向打出——正是想要的效果。

![最终代码](../screenshots/042_new3.jpg)

> 💡 **扩展提示（此处以视频为准）**：课程本节只做左右变向。若以后想加上/下向攻击（如向上挥砍），思路是在 region 内再用 `yInput` 与 `xInput` 组合出一个 `Vector2` 方向后传给 `SetVelocity`——但本节按视频仅处理水平方向。

## 💻 完整代码

### PlayerPrimaryAttackState.cs（042 版）

```csharp
using UnityEngine;

public class PlayerPrimaryAttackState : PlayerState
{
    private int comboCounter;

    private float lastTimeAttacked;
    private float comboWindow = 2;

    public PlayerPrimaryAttackState(Player _player, PlayerStateMachine _stateMachine,
                                     string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Enter()
    {
        base.Enter();

        if (comboCounter > 2 || Time.time >= lastTimeAttacked + comboWindow)
            comboCounter = 0;

        player.anim.SetInteger("ComboCounter", comboCounter);

        #region Choose attack direction
        float attackDirection = player.facingDir;

        if (xInput != 0)
            attackDirection = xInput;
        #endregion

        player.SetVelocity(player.attackMovement[comboCounter].x * attackDirection,
                           player.attackMovement[comboCounter].y);

        stateTimer = .1f;
    }

    public override void Update()
    {
        base.Update();

        if (triggerCalled)
            stateMachine.ChangeState(player.idleState);

        if (stateTimer < 0)
            player.SetZeroVelocity();
    }

    public override void Exit()
    {
        base.Exit();

        player.StartCoroutine("BusyFor", .15f);

        comboCounter++;
        lastTimeAttacked = Time.time;
    }
}
```

Update / Exit 与 041 完全一致，列在这里仅为呈现改名后的完整类。

## 📝 核心要点

- **命名规范**：状态类统一 `State` 后缀；`Ctrl + R, R` + Rename symbols file 一步到位。
- **时机即语义**：方向在 `Enter` 时采样——"每段攻击发起瞬间"的选择窗口，而不是攻击全程实时转向。
- **封装红线**：只读属性不能在外部赋值；改变朝向永远走 `SetVelocity` $\rightarrow$ `FlipController` 这条自动通路。
- **默认值兜底**：无输入时 `attackDirection = facingDir`，行为与旧版完全兼容。
