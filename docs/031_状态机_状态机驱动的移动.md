## 🎯 本节目标

把"读取输入 $\rightarrow$ 移动"的逻辑搬进 `PlayerMoveState` / `PlayerIdleState`，让角色第一次真正在状态机驱动下左右跑动。

> ⏳ **本节只做移动。** 跳跃、冲刺状态要到 032 / 035 节才创建——本节的 Idle/Move 中**不要**提前引用 `jumpState`、`dashState`（写了必然编译错误），对应转换届时再加。

## 🖥️ 操作步骤

### 步骤 1：搭建物理测试环境

- 新建 Platform：Sprite 用 Square，加深颜色，拉宽放低；添加 **Box Collider 2D**。
- Player 添加 **Capsule Collider 2D**（大小包住角色即可）。
- Player 添加 **Rigidbody 2D**：
  - Constraints $\rightarrow$ **Freeze Rotation Z** ✅
  - Interpolate $\rightarrow$ **Interpolate**
  - Collision Detection $\rightarrow$ **Continuous**
  - Gravity Scale $\rightarrow$ **3.5**
- Main Camera 的 Size 改为 **7**，视野更远一些。

### 步骤 2：PlayerState 基类中读取水平输入

输入放在**基类**里，所有状态都能直接用（空中移动、攻击方向后面都要用）：

```csharp
// PlayerState.cs
public class PlayerState
{
    protected Player player;
    protected PlayerStateMachine stateMachine;
    private string animBoolName;

    protected float xInput;   // ← 新增：水平输入

    // ... 三参构造不变 ...
```

```csharp
// PlayerState.Update() 中新增一行
public virtual void Update()
{
    xInput = Input.GetAxisRaw("Horizontal");
}
```

### 步骤 3：IdleState —— 有输入就切到 MoveState

```csharp
public class PlayerIdleState : PlayerState
{
    public PlayerIdleState(Player _player, PlayerStateMachine _stateMachine,
                            string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Update()
    {
        base.Update();

        if (xInput != 0)
            stateMachine.ChangeState(player.moveState);
    }
}
```

### 步骤 4：MoveState —— 设置速度 + 无输入回 IdleState

```csharp
public class PlayerMoveState : PlayerState
{
    public PlayerMoveState(Player _player, PlayerStateMachine _stateMachine,
                            string _animBoolName)
        : base(_player, _stateMachine, _animBoolName) { }

    public override void Update()
    {
        base.Update();

        player.SetVelocity(xInput * player.moveSpeed, player.rb.velocity.y);

        if (xInput == 0)
            stateMachine.ChangeState(player.idleState);
    }
}
```

> 💡 `SetVelocity` 是下一步要在 Player 中新建的函数——以后所有"给速度"的代码都走它，方便统一管理。

### 步骤 5：Player 提供 rb 与 SetVelocity

```csharp
// Player.cs
#region Components
public PlayerStateMachine stateMachine { get; private set; }
public PlayerIdleState idleState { get; private set; }
public PlayerMoveState moveState { get; private set; }
public Animator anim { get; private set; }
public Rigidbody2D rb { get; private set; }      // ← 新增

[Header("Move Info")]
public float moveSpeed;                           // 默认值先给 12
#endregion

private void Awake()
{
    stateMachine = new PlayerStateMachine();

    idleState = new PlayerIdleState(this, stateMachine, "Idle");
    moveState = new PlayerMoveState(this, stateMachine, "Move");
}

private void Start()
{
    anim = GetComponentInChildren<Animator>();
    rb = GetComponent<Rigidbody2D>();             // Animator 在子物体上 → InChildren

    stateMachine.Initialize(idleState);
}

private void Update()
{
    stateMachine.currentState.Update();
}

public void SetVelocity(float _xVelocity, float _yVelocity)
{
    rb.velocity = new Vector2(_xVelocity, _yVelocity);
}
```

运行测试：角色可以左右跑动并播放 Move 动画。最后把 Inspector 里 **Move Speed 调成 8**（12 太快）。

![Player.cs 全貌](../screenshots/031_c.jpg)

### 步骤 6：小清理——rb 上移到 PlayerState

`player.rb.velocity.y` 写起来太长。在基类加一个受保护字段，进入状态时赋值一次：

```csharp
// PlayerState.cs
protected Rigidbody2D rb;

public virtual void Enter()
{
    player.anim.SetBool(animBoolName, true);
    rb = player.rb;
}
```

之后 MoveState 里可以直接写 `rb.velocity.y`。

## 📝 核心要点

```
旧写法 (Player.cs)：
  if (xInput != 0) { 移动 } else { 待机 }
  所有逻辑挤在一个 Update 里

新写法 (FSM)：
  PlayerState.Update()   → 只负责读输入（xInput）
  IdleState.Update()     → 有输入 → ChangeState(moveState)
  MoveState.Update()     → SetVelocity 移动 + 无输入回 Idle
  Player.SetVelocity()   → 唯一的"设速入口"

状态之间互不认识具体逻辑，只通过 stateMachine.ChangeState 切换。
```
